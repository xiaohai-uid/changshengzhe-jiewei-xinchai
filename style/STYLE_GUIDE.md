# STYLE GUIDE V2

## 核心体验

简洁、强节奏、具体观察、基于可见证据推理、信息逐层递进。每章至少一个认知推进，结尾形成新的自然问题。

目标不是“看起来节奏快”，而是**像真实长篇小说一样，让动作、观察、心理和对话自然连成场景。**

## 单章长度与节奏

- 正文硬区间：**2800—4000字**。
- 常规目标：**3200—3600字**。
- 不允许为了赶预定节点在后半章突然压缩场景、连续塞设定或快速完成多次反转。
- 一章优先承载1—2个核心事件；超过容量就跨章，不把完整场景压成剧情梗概。
- 写到约3000—3300字时检查剩余任务。如果还有两个以上关键节点未发生，必须顺延至少一个。
- 后25%篇幅只负责收束本章核心事件、呈现后果、建立下一步因果；禁止突然进行境界科普、世界观总讲解、连续揭谜或多线清仓。
- 低于2800字时，不以重复心理、无效对话、景物填充凑字；应检查章节合同是否过薄，并重构事件容量。

## 分段规则（硬规则）

- 同一动作链、观察链、心理推演必须优先放在同一自然段，不为“显得有节奏”机械拆段。
- 常规自然段优先承载 **2—5句**；段落长短随场景自然变化，不追求整齐。
- 同一说话人连续两三句可以放在同一段；换说话人通常换段。
- 只有真正需要砸节奏的死亡、发现、反转、答案、极强动作节点或关键一句对话，才允许一句或几个字独占一段。
- 连续三个以上一句式叙述段，默认视为 FAIL；除非处于明确的极端动作/崩溃场景且确有必要。
- 禁止“红。白。黑。”“不能。太弱。到他了。”这类短词连续独段。
- 禁止用大量空行人为制造速度感。节奏来自事件压力、句子变化和信息释放，不来自排版。

## 小说世界与后台隔离

正文人物和叙述者不得引用作者后台：
- 禁止“第三章 / 上一章 / 前文 / 本章”式章节回指；
- 禁止 CHxxx、FP-xxx、CHAR-xxx、Canon、Ledger、Snapshot、State Diff、Knowledge Matrix 等仓库语言；
- 禁止把作者层分类标签直接变成人物思维。

回忆必须写成世界内部记忆，例如“上次在西院时”，更优先用当时的触感、气味、动作直接唤回。

## Published Prose Anchor

每章起草前必须回读至少两段已确认发布正文，优先 CH001—CH003 或最近高质量章节。

用途：校准自然段、对话、观察、思考密度。不得复制原句，但必须让新章在纸面质感上属于同一本小说。

## 信息引入规则

- 新概念第一次出现时，读者必须获得足以判断“它大概是什么、与当前人物相比高低如何、为什么此刻重要”的最小上下文。
- 不进行百科式完整解释。只介绍当前场景真正需要的那一层。
- 境界、势力、术法、制度第一次出现，优先通过人物反应、身份差、可见能力、实际后果建立尺度，再补必要名称。
- 禁止仅写“某人是开府境/某级强者”而不给读者任何相对尺度。
- 允许陈缺不知道完整体系；读者的认知可以与陈缺同步逐步扩展。

## 陈缺的推理

必须从读者能看到的证据出发。允许他猜错、验证失败或证据不足。

禁止：
- 没证据直接得出真相；
- 作者事后说“其实他早就知道”；
- 为显示聪明让别人集体降智；
- 把猜测写成事实。

更重要的是：**谨慎应越来越多地通过行为表现，而不是研究报告式解释。**

优先：
- 压住一个猜测不说；
- 暂缓行动；
- 保存退路；
- 选择信息要求更低的方案；
- 因证据不足拒绝下注。

减少反复使用：
- “这不能证明……”
- “这只能证明……”
- “至少说明……”
- “这不代表……”

同类限定句一章反复出现时，必须改写为人物动作或具体选择。

## 高频句式控制

主动减少：
- “陈缺心里一沉。”
- “他忽然明白。”
- “原来如此。”
- “真正的问题是——”
- “他深吸一口气。”
- “微微一怔 / 心头一颤 / 意味深长。”
- “空气仿佛凝固 / 时间仿佛静止。”

不是绝对禁用，但不能成为默认情绪按钮。

## Narrative Pattern / 胜利算法

不仅检查道具和招式，还检查高层算法。

即使道具不同，下列仍视为同一种破局：
- 先看别人踩坑 → 得到完整规则 → 自己精准通过；
- 隐藏/装弱 → 对方误判 → 无代价脱身；
- 偷听内幕 → 得到答案 → 规避危险。

近期重复时必须改变结构：让陈缺在信息不足时先选择、允许误判、让成功产生新暴露面或损失。

陈缺的优势是“不轻信解释”，不是“永远排在后面看完答案再作答”。

## 配角与对话

- 配角必须按自己的目标、风险和信息行动。
- 每个重要配角进入场景前，作者层必须能回答：**如果陈缺不在这里，他自己会做什么？**
- 如果答不出来，人物很可能正在沦为工具人，应先重构场景。
- 对话不是设定问答机；能通过行为和利益冲突呈现的信息，不强迫角色互相解释。
- 同一个人说话的词汇、句长、回避方式应有差异，不要求每个角色都“聪明地说完整话”。
- 赵石不能长期只承担“展示异常”；韩鸦不能长期只承担“送任务/调组”；顾长槐不能只承担“权威检查”。

## Anti-AI 三遍终检

### Pass 1：指纹清扫

优先替换万能升华、万能比喻、万能情绪贴标。能用具体器物、动作、声音、身体限制表达，就不要抽象宣布情绪。

扫描后台泄漏词、章节编号回指、现代测试报告腔。

### Pass 2：句式与段落去重

- 同一个动作如果被写成“动作发生 → 主角感知 → 身体再次反应”三层重复，只留最有效的一层或两层。
- 删除读者已经从场景看懂后又出现的解释句。
- 检查“不是……而是……”“他没有……他只是……”等结构是否连续复用。
- 检查短句是否真的承担节奏作用，而不是机械断行。
- 检查是否出现连续三个以上一句式叙述段。

### Pass 3：章尾钉死

章尾禁止以以下方式收束：
- 总结感悟；
- 强行升华；
- 哲理句；
- “他不知道的是……”式作者预告；
- 重复解释刚刚发生的反转；
- 只靠神秘人突然说一句危险台词制造钩子。

优先用：本章选择导致的现实后果、位置改变、关系变化、制度处置、未完成动作。

## 章节功能

一章优先只做最重要的一至两件事。不要为了“信息量大”同时推进五六条线而让正文变成剧情摘要。

制度/测试场景尤其禁止逐项展示所有样本。普通样本重点保留 1—2 个即可，其余压缩进连续场景，让真正冲突落到主要人物的选择与后果上。

至少保留一个有具体质感、读者能记住的细节，但不要为了制造“名场面”堆砌金句。

## 爽点

爽点主要来自：发现规则 → 理解/验证 → 利用规则 → 承担代价 → 获得新的主动权。

必须强调后两步：**承担代价 + 获得主动权。**

连续两次正确判断都只带来收益、没有新增暴露/损耗/责任/关系债，视为结构风险。

避免长期重复“隐藏实力 / 假装废物”作为主要爽点，也避免同一种信息差破局连续复用。
