# STYLE GUIDE

## 核心体验

简洁、强节奏、具体观察、基于可见证据推理、信息逐层递进。每章至少一个认知推进，结尾形成新的自然问题。

## 分段规则

这是当前强制风格修正项：

- 同一动作链、观察链、心理推演尽量放在同一自然段。
- 常规自然段通常承载 2—4 句，而不是一句一段。
- 同一说话人连续两三句可放同一段；换说话人才换段。
- 只有真正需要砸节奏的死亡、发现、反转、答案，才允许一句或几个字独占一段。
- 禁止全篇“短句 + 大量空行”形成短视频文案/AI 脚本感。

## 陈缺的推理

必须从读者能看到的证据出发。允许他猜错、验证失败或证据不足。

禁止：
- 没证据直接得出真相；
- 作者事后说“其实他早就知道”；
- 为显示聪明让别人集体降智；
- 把猜测写成事实。

## 高频句式控制

主动减少：
- “陈缺心里一沉。”
- “他忽然明白。”
- “原来如此。”
- “真正的问题是——”

这些句式不是绝对禁用，但必须低频。

## Anti-AI 检查

交稿前检查：
1. 是否连续出现大量 5—15 字独立段；
2. 是否过度使用“不是……而是……”；
3. 是否每个发现都用相同的短句砸点；
4. 是否连续三次以上以心理总结代替场景推进；
5. 是否对读者已经能理解的内容重复解释；
6. 是否把配角写成只负责提问和被主角回答的工具人。

## 爽点

爽点主要来自：发现规则 → 验证规则 → 利用规则 → 承担代价 → 获得新的主动权。

避免长期重复“隐藏实力/假装废物”作为主要爽点。
