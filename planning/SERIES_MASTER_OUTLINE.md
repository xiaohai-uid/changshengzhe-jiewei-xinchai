# SERIES MASTER OUTLINE · 全书总纲 V2

> 目标体量：**约200万中文字**。规划安全区间约190万—210万字；常规单章3200—3600字，允许2800—4000字。
>
> 预计 **8卷、约580—620章**。章号、卷长和Arc长度均为弹性规划，不是Canon；已发布正文事实、世界硬规则、核心人物弧和终局命题优先。
>
> 新原则：不为了“长篇感”拉长情绪。一个问题如果已经得到足够证据、人物已经完成选择，就进入下一层，不再用同类事件反复证明。

## 一句话总纲

陈缺从白骨山一个被当成药材培养的下品木灵根少年开始，在一次次破解修炼制度的过程中发现：力量从来没有免费来源，所谓长生不是逃离代价，而是把代价推迟、转移或重新承担；最终他面对的不是“打败邪恶天道”，而是如何改变一个让强者把偿还成本不断压给弱者的修仙文明。

## 核心成长线

**发现规则 → 理解规则 → 利用规则 → 掌握力量 → 看见代价分配 → 修改局部规则 → 承担修改规则的后果 → 追踪规则来源 → 建立新的偿还方式。**

200万字版本必须比旧长规划更早进入“利用/掌握”阶段，避免陈缺长期只承担观察与解谜功能。

## 商业节奏总原则

全书采用：**期待 → 兑现 → 升级**。

- 每卷必须有一个清晰的正向期待，不只是不死/不暴露。
- 每个Arc结束后，陈缺至少留下能力、资源、身份、权限、关系筹码、现实影响或关键认知中的一项可累积资产。
- 代价可以污染收益，但不能习惯性把重大收益立即归零。
- 信息可以是奖励，但不能长期成为唯一奖励。
- 同一类情绪与解决算法连续重复时，宁可提前收束Arc，也不靠换场景拖字数。

## 三大阶段

### PHASE I · 我为什么会被吃（VOL01—VOL04，约90万—100万字）

从白骨山人体药材机制出发，先建立陈缺自己的修炼路，再进入正常修仙社会、公共灵脉与古代失败文明。

阶段终点：确认“天地亦食修士”不是一句恐吓，但天地也不是放大版白骨山；修炼是一个真实的取得与归还循环。

### PHASE II · 谁在替谁偿还（VOL05—VOL06，约45万—55万字）

把成本从自然现象推进到制度与权力：仙籍、配额、代偿、不同文明的归还方式、归欠与长生者问题集中展开。

阶段终点：“长生者皆为薪柴”得到第一层完整意义；真正的问题变成文明如何把自己的归还责任转给别人。

### PHASE III · 能不能换一种还法（VOL07—VOL08，约50万—60万字）

界外代偿与天倾逼旧账同时结算。陈缺经历一次“聪明不能让总成本消失”的重大失败后，从破解者转向制度设计者。

阶段终点：建立“谁取谁偿、活着持续归还、不能无限外包”的新修炼秩序。长生仍有代价，世界也没有被彻底治愈。

# VOL01《白骨山》

**功能**：从“被当成药”推进到“拥有自己的力量、职业价值和第一份主动权”。

**必须完成**：七日考核、韩鸦交易阶段结果、赵石药房异常第一层、药圃真炼身、血虫批次异常第一层原因、周玄尸体回收、白骨山产业链、外部交药与离山。

**核心兑现**：陈缺不只活下来，还要依次获得药材处理价值、稳定资源接口、炼身能力、组织议价筹码与最终离山出口。

**卷末认知**：血虫是白骨山的人为养药机制，不是修仙本身；真正修炼同样消耗资源和自身。

# VOL02《青河之外》

**功能**：用真实修仙社会纠正陈缺对白骨山经验的过度外推，同时让真正修炼进入可见成长与资源竞争。

**核心体验**：市场、合作、正常宗门、资源争夺、第一次稳定开府。

**核心兑现**：陈缺第一次拥有不是靠伪装得来的正常修士身份与关系网络；药材专业能力从求生工具变成谋生与交换资源的资本。

**卷末认知**：正常修仙不是骗局，但力量仍需要食物、灵材、土地、矿脉和身体共同支付。

# VOL03《南岭灵脉》

**功能**：把“个人修炼成本”升级为“公共资源冲突”，同时回收白骨山异常虫种与衰竭灵脉的联系。

**核心体验**：枯脉、配额、宗门利益、凡俗生计、多方资源博弈。

**核心兑现**：陈缺第一次不只是利用既有制度求生，而是改变一项局部资源分配结果，并因此承担责任。

**卷末证据**：高阶修士死亡后局部灵脉恢复，第一次出现“修士会把东西还给天地”的强证据。

# VOL04《旧天遗城》

**功能**：通过一个曾经真正成功过的封灵文明，纠正“天地就是更大的白骨山”这一错误外推。

**核心体验**：遗迹调查、繁荣旧证、历史立场、循环断裂、结丹。

**核心兑现**：陈缺获得第一次对高阶循环有实际作用的能力/身份，同时失去“只要把回收机制关掉就会更好”的简单答案。

**卷末认知**：天地回收更像结构性循环；真正值得反抗的是文明把自己的归还责任偷偷外包给弱者。

# VOL05《仙籍诸法》

> 合并旧“仙籍”与“沧海诸法”，避免把“制度不公平”和“另一种修炼法”分别拉成两整卷。

**功能**：先看到成熟治理如何记录成本，再立刻用另一文明的实践检验“有没有别的偿还方式”。

**核心冲突**：仙籍、灵脉责任、合法代偿与特权；南海周期归还法成长更慢、地域绑定更强，却能显著降低长期损耗。

**核心兑现**：陈缺从只会指出漏洞，推进到能比较两套都能运行的制度，并第一次做出一个局部可持续方案。

**卷末状态**：进入元神；“活着持续归还”出现可行雏形，但远未成为天下答案。

# VOL06《天债长生》

> 合并旧“天债”与“长生盟”，让真相揭示与理念对手在同一卷互相验证，不再先讲一卷理论、再讲一卷知道理论的人。

**功能**：确认归欠、死亡回流与长生悖论，让长生盟/守衡派直接进入冲突。

**核心冲突**：长生者不愿被当作天然牺牲品；守衡派不接受少数人无限占有；大型代偿工程把高层成本导向别处。

**韩鸦**：本卷完成其长期镜像选择——真正自由是否必须由更弱者替他付账。

**核心兑现**：陈缺进入法域，第一次拥有“自己的规则会让一地承担影响”的真实权力。

**卷末认知**：“长生者皆为薪柴”得到第一层完整意义；天地无道德判断，但文明决定谁先被烧。

# VOL07《界门天倾》

> 合并旧“界门”与“天倾”。界外代偿必须很快产生回流后果，不能再隔一整卷才结算。

**功能**：把白骨山“让别人当药”的结构扩大到世界尺度，并证明关闭剥削本身也不能消除历史欠账。

**核心冲突**：依附小界、关闭界门、归欠回流、三类危机方案、世界级失衡。

**重大失败**：陈缺尝试兼顾所有方，因总成本没有消失而造成真实损失，彻底打掉“设计得够聪明就能无损通关”的幻想。

**核心兑现**：陈缺合道，获得世界级权柄，同时被地域责任绑定。

**卷末状态**：旧秩序不可逆崩解；“第三条路”必须从思想变成可运行制度。

# VOL08《薪柴》

> 合并旧“改律”与“薪柴”。终卷不再先用一整卷试制度、再用一整卷收尾，而是“试验—失败—修正—旧债结算—终局”连续推进。

**功能**：把活偿从局部技巧变成可执行制度，并处理数千年旧债与长生者归还问题。

**必须经历**：第一批活偿失败、作弊与转嫁；可追踪责任机制；既得利益反扑；部分地域成功；旧债名单与“谁先燃”；陈缺本人支付新规则启动成本；最后的旧秩序冲突。

**终局原则**：
- 修士食天地，是取得；
- 天地食修士，是归还；
- 长生者成为薪柴，是长期延迟归还后的集中结算；
- 真正的问题不是想长生，而是把自己的结算永久伪装成别人的义务；
- 新秩序不能消灭代价，只让取得与偿还更对应、更透明、更难无限外包。

陈缺可以触及长生，但不能成为无成本不朽者。结尾必须让他仍处在自己建立的偿还规则之内。

# 全书压缩规则

1. **一个世界观结论只允许完成一次主证明。** 后续只展示新后果，不重复用不同城市/秘境证明同一句话。
2. **一个理念对手必须同时承担人物与剧情功能。** 不新增只负责讲观点的人。
3. **地点变化必须带来规则变化。** 如果换地图只是换名字继续同类宗门冲突，则删除或合并。
4. **连续两个Arc若主要奖励同为信息，后一个必须改成能力/资源/身份/关系/现实影响。**
5. **旧伏笔优先于新增谜题。** 200万版本更强调回收密度。
6. **终局最迟在约75%篇幅进入不可逆倒计时。** 不到最后几十章才突然出现天倾。
7. **不为境界凑卷。** 境界突破服从人物与代价，不要求一卷只升一个固定境界。
8. **任何未来扩写超过约210万字，必须先做Macro Drift Audit。** 只有人物/因果真实需要时才扩，不允许因为“还能写”自动加卷。
