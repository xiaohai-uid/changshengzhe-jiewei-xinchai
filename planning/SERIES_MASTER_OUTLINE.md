# SERIES MASTER OUTLINE · 全书总纲 V1

> 目标体量：约 350万—500万中文字，常规单章 3200—3600 字，允许 2800—4000。预计 12 卷、约 1200—1450 章。章节号和卷长是弹性规划，不是 Canon；卷级功能、核心真相推进和主角成长方向属于中长期锁定。

## 一句话总纲

陈缺从白骨山一个被当成药材培养的低等灵根少年开始，在一次次破解修炼制度的过程中发现：力量从来没有免费来源，所谓长生不是逃离代价，而是把代价推迟、转移或重新承担；最终他面对的不是“打败邪恶天道”，而是如何改变一个让强者把偿还成本不断压给弱者的修仙文明。

## 核心成长线

**发现规则 → 理解规则 → 利用规则 → 掌握力量 → 看见规则背后的利益分配 → 修改局部规则 → 承担修改规则的后果 → 追踪规则来源 → 建立新的偿还方式。**

陈缺前期最大的能力是“不轻信别人给的解释”；中期必须面对“仅仅看穿系统不等于能建立更好的系统”；后期真正的成长是愿意为自己建立的规则承担成本。

## 全书三大阶段

### 第一阶段：我为什么会被吃（VOL01—VOL04）
从白骨山人体药材机制出发，逐步确认血虫只是人为附加机制，真正修炼也会消耗环境、肉身和寿命。陈缺从个人生存走到理解修仙资源循环。

阶段终点：确认“天地亦食修士”不是一句恐吓，但天地也不是白骨山式的幕后牧场主。

### 第二阶段：谁在替谁偿还（VOL05—VOL08）
进入高阶修仙制度。陈缺发现修仙文明早已部分认识修炼成本，于是发展出仙籍、灵脉配额、代偿阵、附属区域等制度。问题从“有没有代价”升级为“代价被谁承担”。

阶段终点：确认长生者积累的归欠最终会在天地失衡时被优先回收，“长生者皆为薪柴”第一次得到完整作者层/主要角色层意义。

### 第三阶段：能不能换一种还法（VOL09—VOL12）
界外代偿暴露，主世界危机加速。陈缺不能靠摧毁一个反派解决问题，因为关闭转嫁渠道本身会让积压代价立刻回到主世界。他必须从破解者变成设计者，在不违反“没有免费力量”的前提下寻找持续偿还的新制度。

阶段终点：建立“谁取谁偿、活着持续归还、不能无限转嫁”的新修炼秩序。长生仍有代价，世界也没有被彻底治愈，但隐藏成本不再能轻易向下层无限外包。

# 十二卷骨架

## VOL01《白骨山》

**规模建议**：约 CH001—CH120/130。

**核心问题**：白骨山到底在培养什么？陈缺怎样从“假装修炼”变成真正拥有自己的修炼道路？

**主角境界**：凡人 → 引气 → 炼身初步。

**必须完成**：七日考核、韩鸦交易、赵石药房异常、血虫批次异常、周玄尸体用途回收、白骨山产业链、残篇代价第一层、离开白骨山。

**卷末认知**：血虫是白骨山的人工养药机制，不是修仙本身；真正修炼同样会真实消耗资源和自身。

**卷末状态**：陈缺离开白骨山，但不是毁灭整个宗门后无敌出走；白骨山体系受到冲击仍可能存在，韩鸦/赵石/顾长槐至少部分人继续进入长期线。

## VOL02《青河之外》（工作名）

**核心问题**：如果血虫不是修仙，那么“正常修仙”是什么？

**主角境界**：炼身 → 开府。

陈缺进入真正的修仙市场、商路和正常宗门体系，第一次看到不把弟子当药的修炼方式。他必须纠正“全天下都是白骨山”的过度外推，同时发现正常修炼的成本同样落在灵田、矿材、妖兽、食物和修士肉身上。

卷末通过开府第一次明确：要把灵气长期变成自己的力量，必须付出更深的炼化与命痕成本。

## VOL03《南岭灵脉》（工作名）

**核心问题**：一个区域能承受多少修士？

**主角境界**：开府 → 凝真。

地方灵脉衰退、宗门配额和凡俗生计发生冲突。陈缺接触镇脉体系，发现修炼不仅是个人选择，而是具有公共资源成本。白骨山血虫异常的底层原因在这一卷得到更深回收：它与衰竭灵脉产生的返灵/归息现象有关，而非单纯“虫种质量差”。

卷末出现高阶修士死后局部灵脉短暂恢复的现象，第一次给“天地吃修士”留下自然层证据。

## VOL04《旧天遗城》（工作名）

**核心问题**：如果一个文明拒绝归还，会发生什么？

**主角境界**：凝真 → 结丹。

陈缺进入古代废城/旧法域，追查一个曾经成功把灵气长期封闭在城内的文明。遗迹不是单纯寻宝副本，而是一场历史因果调查：它曾繁荣数百年，最后因循环被彻底截断而发生规则级崩坏。

卷末大反转：天地的回收不是“恶意收割”，而是世界维持循环的结构性过程。陈缺此前把白骨山逻辑无限外推的猜测被部分推翻。

## VOL05《仙籍》（工作名）

**核心问题**：既然高阶文明知道成本，为什么世界仍然这样？

**主角境界**：结丹稳定期。

进入中州/大型修士治理体系。仙籍、灵脉占有、法域登记和资源税说明高阶社会早已知道修炼会产生公共成本。真正的问题是有权者可以购买、转移、豁免自己的责任。

陈缺第一次不只破解自然规则，而是参与制度博弈。顾长槐或白骨山旧线在更大药材网络中回归，让读者看到地方恶制背后的市场与治理接口。

卷末揭示“代偿”已经被合法制度化。

## VOL06《沧海诸法》（工作名）

**核心问题**：有没有不靠无限占有也能修炼的文明？

**主角境界**：结丹 → 元神。

南海群岛采用与东陆不同的修炼制度，部分流派依靠潮汐周期“取一部分、还一部分”，因此环境损耗较小，但代价是成长慢、地域绑定强、爆发能力弱。

本卷作用不是给最终答案，而是证明“偿还方式可以不同”。陈缺第一次看到可持续修炼的雏形，同时也看到它无法直接复制到整个天下。

卷末形成最终“活偿”理念的第一颗真正种子。

## VOL07《天债》（工作名）

**核心问题**：修士死后，力量去了哪里？

**主角境界**：元神稳定/深化。

通过灵脉危机、古修士死亡遗留和多地证据，陈缺确认：修士把弥散灵机炼得更加有序，死亡/归还后这些力量会反哺世界规则。高阶文明把长期未归还的差额称为“归欠/天债”等不同名字。

系列中点真相：修士既是掠夺者，也是炼化节点。天地没有设计骗局，但它确实最终从修士身上获益。

卷末首次出现“大归潮/天倾”历史记录，以及“长生者先燃”一类古老表述。

## VOL08《长生盟》（工作名）

**核心问题**：知道自己最终会成为薪柴的长生者，会做什么？

**主角境界**：元神 → 法域。

长生盟正式进入核心舞台。他们了解归欠与回收规律，因此发展出代偿阵、地域绑定、契约转移和其他延寿手段。与之对立的守衡派也并非完全正义，其中有人主张强制让高阶修士提前归还。

陈缺第一次处于两套都能自圆其说的高阶制度之间。韩鸦长期线在这一阶段完成重大转折：他是否继续把自由建立在别人承担成本之上，必须付出结果。

卷末确认大规模天地失衡正在逼近。

## VOL09《界门》（工作名）

**核心问题**：一个世界能不能把自己的代价扔给另一个世界？

**主角境界**：法域深化。

陈缺通过界门进入依附小界/破碎地域，发现部分顶级势力把资源消耗与归欠倾倒到外界，使主世界维持数千年繁荣。

这在文明尺度上重新映照白骨山：强者把别人变成自己的“药”。但此时陈缺已经知道，这不是天地强迫，而是制度选择。

关键困境：如果立即切断所有界外代偿，主世界积压的归欠会骤然回流，造成更快的灾难。

## VOL10《天倾》（工作名）

**核心问题**：当欠下的代价必须现在结算，谁该先付？

**主角境界**：法域 → 合道。

世界级失衡开始。长生盟主张扩大代偿；激进守衡派主张焚毁/强制回收高阶长生者；底层区域则要求停止被牺牲。

陈缺尝试保护所有人会遭遇一次重大失败，因为系统里没有凭空消失的成本。

他通过与受损地域合道获得更高权柄，同时也失去部分自由：力量越大，责任越具体。

卷末不是胜利，而是确认旧方法全都无法无损解决危机。

## VOL11《改律》（工作名）

**核心问题**：规则能不能改？改了以后谁来承担新成本？

**主角境界**：合道。

陈缺开始把“活偿”从局部技巧变成可运行制度。试验必须出现失败：有人因为持续归还导致境界跌落，有地域因回流方式错误受损，有势力利用新规则套利。

陈缺从“找到正确规则”成长为“建立能被普通人和坏人都使用的制度”。最终形成原则：谁截取、谁承担持续归还；转移成本必须可见、可追踪、不能无条件压给无权者。

卷末新体系在有限区域成功运行，但旧长生秩序发动最后反扑。

## VOL12《薪柴》

**核心问题**：长生到底意味着逃离死亡，还是承担更长久的归还责任？

**主角境界**：合道极深 → 触及长生，但不获得免费永生。

终局冲突不是单纯击杀一个最终BOSS，而是围绕“谁承担数千年积累的归欠”展开。部分古老长生者的债已经无法通过温和活偿消化，必须有人真实归还；陈缺不能让所有历史成本凭空消失。

他以自身道果/寿命承担新规则启动的一部分成本，完成从利用规则到承担规则的最终人物闭环。

终局建立的不是乌托邦，而是一种更难隐藏成本的新秩序：长生仍然存在，修炼仍然消耗天地，但长期占有者必须持续偿还，不能无限把自己应付的代价变成下层的死亡。

最终主题回扣：**借来的东西，总要还。真正的问题从来不是还不还，而是谁来还、什么时候还、能不能让取走的人自己承担。**

# 不允许偏离的系列原则

1. 白骨山真相不能直接等同全世界真相。
2. 天地不是人格化终极反派。
3. 没有免费力量、免费长生、免费改革。
4. 陈缺不会一路靠隐藏实力和信息差赢；中后期必须承担公开责任和治理失败。
5. 每卷至少改变一次陈缺对“修炼/制度/代价”的理解，而不是只换地图升级。
6. 每卷结尾都要使下一卷问题自然升级：个人 → 宗门 → 地域 → 历史 → 制度 → 文明 → 世界。
7. 12卷终点锁定，具体卷长和中间人物允许随真实正文因果调整。
