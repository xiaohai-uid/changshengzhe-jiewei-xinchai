## CH010 · 少了一个人以后

### 因果起点

- CH009章末陈缺在南二桌边。
- 老马已从西侧废料路返回，TARGET-0001尚未回来。
- 南二屋内仍在正常称药、记数、搬篓；还没有全场停摆。
- 赵石半日借工仍有效，午后到期。
- 陈缺二验处置已落地：先留南二，三日后复验；真木属灵气仍近空。
- 韩鸦CH009未出场，不知道章末变化。

### 核心方向

Scene Card必须先从南二真实责任链长出，而不是直接跳到“韩鸦来抓人”。

优先自然碰撞：
1. 木筹/搬运人数/门口记录确认TARGET确实超时未归；
2. 老周、守门或带队灰衣基于各自责任决定先找、先压、还是上报；
3. 陈缺必须选择自己是否补充TARGET此前试门行为，以及说多少；
4. 韩鸦若通过合理渠道得知，必须为自己的窗口亲自付出行动成本。

### 主动性要求

- 陈缺不能知道TARGET在哪里；只能基于“同行已回、本人未回、此前试门”判断风险。
- 他必须在信息不完整下决定：把旧观察全部上报、部分保留，还是先验证一个低成本事实。
- 这个选择不能只是“聪明保密”；必须改变至少一个现实结果。
- 不允许再次通过韩鸦威胁谈判获得让步。
- 不允许靠战力追人。

### 本章兑现方向

优先：`IMPACT / LEVERAGE / RELATIONSHIP CONSEQUENCE`。

至少落一项：
- 南二/韩鸦/带队人因为TARGET未归承担真实责任或暴露；
- 陈缺的记录位置让他在“谁最后见过/谁记了哪一篓”中成为关键证人，从而获得或失去一种现实主动权；
- 韩鸦第一次必须做一件只有他会做的高风险实际动作，而不是继续下命令；
- TARGET的计划被陈缺的选择迫使改变，但不要求抓到或杀掉。

主奖励不许只是“知道门下还有一条路”。

### 成本

- 陈缺可能被卷入失踪责任链；
- 韩鸦对其“没盯住”产生真实警惕/债；
- 南二工作位置可能更重要也更危险，但不能无因取消；
- 赵石午后期限逼近，陈缺不可能同时解决所有人。

### Memory

不要求新锚。

若自然形成，优先：韩鸦面对“TARGET的大规模逃亡会坏自己窗口”时的具体行动，或陈缺第一次主动承担自己影响流程后留下的责任。禁止金句补锚。

## CH011—CH012 · 考核小高潮 / 第一Arc收束

### 必须汇合但不清仓所有世界线

- TARGET逃亡动作与其真实规模；
- 韩鸦交易为何在当前时点必须推进到结果；
- 赵石半日借工之后的选择/处置；
- 陈缺南二工作身份与三日复验如何被当前事件重新计算；
- 本批血虫异常只作为制度压力背景，不揭根因；
- 考核从“移动筛查”真正形成阶段分类/去向。

### 结构要求

1. TARGET即使没有陈缺也推进计划。
2. 韩鸦服务自己的脱控利益，不导师化、不为新人义举。
3. 赵石自己决定怎样利用/拒绝工作或治疗路径，不被陈缺代替选择。
4. 陈缺允许错判一个变量；不能全知通关。
5. 小高潮至少让制度方、韩鸦、TARGET其中一方因陈缺的选择付出真实成本。
6. 不预锁陈缺亲手杀TARGET；可以是阻止大规模逃亡、改变时点、放走/留下某人、迫使交易转向，但必须由正文证据决定。
7. 不复制虫爆场面。

### Arc必须兑现

考核结束后：
- 陈缺进入“虫气偏弱但宿主稳定、木灵根、懂药、可使用”的观察/药工/药圃接口；
- 至少保留稳定资源或工作区域接触渠道；
- 韩鸦交易形成真实债与警惕，不能复位；
- 顾长槐/外山对陈缺价值判断改变；
- 赵石进入特殊观察/工作/治疗路径，保持独立目标；
- 陈缺已经完成一次“用位置改变别人/制度结果”的实际行为，不再只是理解规则。

### Arc Memory Audit目标

- 可复述场面已有：周玄之死、山门、CH009“借半日”候选。
- 顾长槐强性格瞬间已有；陈缺强行动瞬间已有候选，待小高潮验证是否真正成立。
- 可回响锚已经足够，不新增口号。
- Arc结束后普通读者应能复述阶段变化：从“被分拣的异常药材”变成“白骨山开始主动使用、其位置能够改变一点处置的人”。最终用词到收束时再锁。

### Arc成本

新身份不是自由：更深册籍、职责、监督，而且越有用越难被随便放走。
