## CH012 · 第一Arc收束 / 阶段分类落地

### 因果起点

- TARGET至少已越过废沟第一道石界；西坡出现封锁哨声，外层结果UNKNOWN。
- 韩鸦已经公开追捕失败并暂停杀人交易，不可能无代价恢复成原来“等陈缺去杀”的状态。
- 南二西门/旧泄沟暂时失效，人员与药材正在东棚继续工作。
- 陈缺被老周明确留下下午继续跟南二；这是现实工作价值，但还不是永久身份。
- 赵石已经回药房方向；其后续具体处置UNKNOWN。
- 陈缺三日复验仍在，白绳黑点/极弱虫气/气路异常仍需要阶段性结论。

### 本章核心功能

CH012是ARC-V01-01收束章，不再继续扩写“搜索过程”。

必须让至少两个已悬着的结果真正落地：
1. TARGET这次逃亡的**阶段结果**；
2. 陈缺当前考核/工作分类的**阶段结果**。

赵石药房线可以给一个可见后果，但不能和TARGET、陈缺分类三线全部写成同等篇幅的完整结算；若容量不足，赵石只留下明确新状态并转入下一Arc。

### TARGET线

允许的阶段结果：
- 被更外层截住/受伤带回；
- 暂时未被抓到，但白骨山确认其已真正越出某层控制范围；
- 留下足够硬的后果使“杀人交易”无法按原计划恢复。

硬保护：
- TARGET失败也必须来自自身计划与白骨山现实规则碰撞，不是为了证明韩鸦或陈缺更聪明。
- 不能突然出现此前毫无证据的庞大同伙网络。
- 若仍未抓到人，本章必须把韩鸦交易推进成真实债/转向/延期条件，不再只说“先停”。

### 陈缺分类

Arc结束时至少兑现三项中的两项：

1. **STATUS**：进入“虫气偏弱但宿主稳定、木灵根、懂药、可使用”的观察/药工/药圃边缘分类；
2. **RESOURCE INTERFACE**：获得稳定接触药食、活木灵机、低阶灵材或固定工作区之一；
3. **FREEDOM/LEVERAGE**：不再能被普通流程随手丢弃，至少一项处置必须考虑其工作价值/责任归属。

同时必须有成本：
- 更深册籍；
- 固定职责；
- 复验/监视；
- 顾长槐或韩鸦更高警惕；
- 对赵石/TARGET事件形成现实责任。

### 顾长槐

若介入，必须通过CH011已经发生的正式上报/西坡封锁产生渠道。

他的判断核心应是：
- 逃亡事件造成的生产/责任损失；
- 陈缺这类异常宿主目前是否“可用”；
- 南二/药圃是否值得继续占用这个人。

不能突然变成给主角讲世界真相的导师。

### 赵石

CH011已明确他自主回药房，因此CH012不能反悔写成“其实没去”。

允许：
- 陈缺看见/听见一个真实渠道传来的药房后果；
- 赵石本人短暂回场并带身体变化；
- 暂不回场，但其状态被明确为某个新流转节点。

禁止：
- 赵石突然知道全部血虫真相；
- 赵石只为了给陈缺送情报而存在；
- TARGET事件巧合证明赵石涉案。

### 陈缺主动性

本章不能只等分类结果砸下来。

他至少要在“正式工作价值 vs 更深控制”之间做一个有限选择，例如：
- 接受一个能接触资源但必须登记/复验的位置；
- 拒绝一个短期更安全却会失去资源接口的安排；
- 利用南二/东棚已经形成的工作信用争取一个具体条件。

选择必须基于当时可见信息，允许他低估未来控制成本。

### Truth ceiling

允许更清楚确认：
- 血虫不是修炼本身；
- 白骨山把工作、筛查、药房和修炼全部纳入养药管理。

禁止：
- 解释异常批次根因；
- 解释“归欠”；
- 宣布整个修仙文明都是养殖场；
- 提前解释“天地亦食修士”的终极含义。

### Arc Memory Audit

CH012结束后必须检查：
- 陈缺这11/12章的阶段变化是否一句话可复述；
- MA-009赵石借半日、MA-010韩鸦写名下去、CH011割断青绳是否都产生了后果；
- 若现有场面已经足够，不再硬造新的哲理金句。

## CH013—CH015 · 下一Arc接口

### ARC-V01-02 · 药圃与真炼身

阶段方向：
- 陈缺进入稳定药材/活木灵机资源接口；
- 药铺经验继续有价值，但不再每章靠认药解题；
- 真修开始从“能引气”推进到真正炼身，并出现具体可见能力差异；
- 轮截/分段吸纳可降低草木损耗，但牺牲速度或效率；
- 真修代价从“草衰、饥饿、寒意”继续获得可观察证据，但终极机制仍不解释；
- 赵石药房后遗症建立为独立人物线；
- 形成“职业价值 → 资源接口 → 真修增强 → 职业价值提高”的正循环，同时组织控制变深。

### 下一Arc第一批问题必须来自旧因果

优先：
- 南二/药圃为什么愿意把低阶药材或活木资源交给陈缺，谁承担损耗账？
- 同样是活木/药材，不同状态对陈缺真修留存与代价为何不同？
- 赵石回药房后的身体反应与陈缺无虫真修究竟哪里不同？
- 西门/旧泄沟事件是否改变外山对新人流转的管理方式？

禁止为了换Arc突然抛出第三方神秘组织或无前置证据的大阴谋。
