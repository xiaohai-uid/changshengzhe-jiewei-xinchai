## CH009 · 资产开始产生外部后果

### 因果起点

- CH008章末陈缺留宿南廊。
- 次日早饭后先去南二；二验等叫。
- 右臂仍伤，普通伤膏只有表层缓解；真木属灵气仍几乎耗尽。
- 韩鸦当前只要求观察TARGET西门行动，不主动制造废料/接触。
- TARGET不会等陈缺准备好，会按自己的计划继续行动。

### 核心方向

CH009不预锁具体事故。Scene Card必须从当天真实流程中选择**1—2个自然碰撞**：
- 南二工作与二验叫号发生时间/职责冲突；
- TARGET利用真实流转窗口推进逃亡准备；
- 赵石特殊观察路径与南二/二验产生交叉；
- 血虫异常迫使制度方临时调整原定流程。

重要的是让陈缺面对一个：

> **保住自己已经争到的位置**
> 与
> **利用这个位置改变某个现实结果**

之间不能同时完全满足的选择。

### 主动性要求

- 陈缺必须在信息不完整时先选择；允许判断漏掉一个变量。
- 选择应使用此前累积资产，但不能把“药材专业知识”本身再次写成主解。
- 不允许靠真灵气恢复/临时爆种解决。
- 不允许用再次谈判韩鸦作为主高潮。

### 本章兑现方向

优先：**IMPACT / STATUS / RELATIONSHIP consequence**。

即使CH009只完成部分兑现，章末至少应看到：
- 陈缺的一个选择让原本会发生的流转/处置发生了变化；或
- 南二位置因他承担责任而变得更稳/更危险；或
- TARGET/赵石/韩鸦必须因为陈缺的选择改计划。

主奖励不能只有“知道一个新秘密”。

### 成本

变化必须让陈缺承担真实代价，例如：
- 更深记录；
- 丢失一部分行动窗口；
- 与某人形成新债；
- 暴露自己比“普通新人”更能影响流程；
- 二验风险被推到更近。

但不得把南二入口无因直接取消，回到原点。

### Memory Anchor

**不要求CH009必须造名场面。** Scene Card可以写 `NO NEW ANCHOR`。

若自然产生高记忆候选，优先来自陈缺“为了改变现实结果承担成本”的动作场面，而不是哲理台词。

短期不复读：
- MA-006“救/废/门”的原句或同义口号；
- MA-008“因为师兄没去”；
- 两文钱，除非赵石真的以独立行动让其意义发生变化。

## CH010—CH011/12 · 考核小高潮与阶段分类

### 核心碰撞

从以下真实线中自然汇合，不要求一章清仓：
- 本批血虫异常；
- 韩鸦交易；
- TARGET-0001逃亡动作；
- 赵石特殊转运；
- 陈缺无虫真修；
- 白骨山分流制度；
- 南二工作入口；
- 陈缺与韩鸦第一次有限边界。

### 结构要求

1. TARGET即使没有陈缺也会推进逃亡。
2. 韩鸦的干预服务自己的脱控/利益目标，不导师化。
3. 赵石按自己的避药房目标行动，不是事故按钮。
4. 陈缺允许错判一个变量，不能全知通关。
5. 若出现虫爆/药液事故，不复制周玄/西院“虫从身体炸出来”的震撼模板；新的冲突必须有不同机制与情绪功能。
6. 不锁死陈缺亲手杀TARGET。
7. 小高潮必须让制度方/韩鸦/TARGET至少一方因陈缺的选择真实付成本，而不是永远只有陈缺付。

### Arc必须兑现

考核结束后：
- 陈缺进入“虫气偏弱但宿主稳定、木灵根、懂药、可使用”的观察/药工/药圃接口；
- 至少保留一条稳定资源或工作区域接触渠道；
- 韩鸦交易形成真实债与警惕，不能复位；
- 顾长槐/外山对陈缺价值判断改变；
- 赵石进入特殊观察路径并保留独立目标；
- 陈缺第一次不只“看懂规则”，而是让一项制度结果因为他的选择发生偏移。

### Arc Memory Audit目标

Arc收束前自然满足：
- 已有强场面：周玄之死/白骨山开篇场面；
- 顾长槐已有强性格瞬间；
- 陈缺仍需要一个真正由主动选择形成的强行动场面；
- 已有多条可回响锚，不再强加新的口号；
- Arc阶段变化最终应能用一句普通话复述，但现在不提前写死。

### Arc成本

新身份不是自由：更深册籍、职责、监督，而且“有用”会让白骨山更不愿放人。
