## Series · 《长生者皆为薪柴》

长期成长：发现规则 → 理解规则 → 利用规则 → 掌握力量 → 看见代价分配 → 修改局部规则 → 承担规则后果 → 追踪规则来源 → 建立新的偿还方式。

### Phase I · 我为什么会被吃（VOL01—VOL04）
从白骨山人体药材机制，推进到真正修炼的资源/环境成本，并完成“天地不是人格化养殖者”的第一次大纠偏。

### Phase II · 谁在替谁偿还（VOL05—VOL08）
进入仙籍、代偿、归欠和长生者制度，确认强者如何把自然代价向下转移。

### Phase III · 能不能换一种还法（VOL09—VOL12）
界外代偿与天倾迫使旧账结算；陈缺从破解者成长为制度设计者，最终建立持续、透明、不能无限外包的活偿路径。

## CURRENT · VOL01《白骨山》

**卷状态**：ACTIVE。
**Canon Horizon**：CH006。
**Next**：CH007。

### 第一卷长期读者承诺

不是“陈缺不断发现白骨山还有更深秘密”。

而是让读者看见一条持续累计的变化：

**一株可以被随时处理的药材**
→ **出现异常、暂时值得观察的人**
→ **因为药材处理能力变成白骨山需要使用的人**
→ **获得资源、身份和局部权限**
→ **开始能和控制他的人谈条件**
→ **最终利用这些长期积累离开白骨山。**

每一步都必须同时带来更深控制、责任或成本，但不能把上一步获得全部清零。

### ARC-V01-01 · 提前的七日考核

- 状态：ACTIVE
- 起点：CH001
- 预计收束：约CH010—12，按场景容量弹性调整
- 当前锚：CH006末，陈缺以白绳黑点进入二验，与四名青绳新人一同被点往南二，其中包括韩鸦交易目标。
- 核心冲突：异常血虫批次导致白骨山提前分流；韩鸦交易、赵石药房后状态、另一名知情逃亡者、陈缺无虫真修与分流制度碰撞。
- 当前正向期待：陈缺不能再只是“过下一关”，而要在考核里第一次证明一种**白骨山会保留并使用的现实价值**，把自己从纯培养对象推向“有用但需观察”的位置。
- Arc 主要兑现：获得新的组织身份/活动空间 + 第一项可持续资源/工作接口；韩鸦对他的关系开始从“单向把柄”出现“需要他的价值”的种子。
- Arc 成本升级：更深记录、固定职责、更多监视和更高暴露面至少一项。
- 禁止：普通擂台、靠热水伪装再次破局、陈缺直接杀穿外山、把南二写成又一轮样本说明书。

### ARC-V01-02 · 药圃与真炼身

约CH011—30，按因果弹性调整。

**读者期待**：陈缺终于有条件把“真修存在”变成“真修真的越来越能用”，并让青河县药铺经验从背景变成持续竞争力。

**主要兑现**：
- 获得相对稳定的活木灵机/药食/低阶灵材接触渠道；
- 真修从引气向炼身推进，至少出现数次清晰“以前做不到、现在能做到”的能力差异；
- 药材辨识、处理、保存、配伍经验使陈缺成为可以被具体工作依赖的人，而不是只有主角自己知道自己有用；
- 轮截降低草木损耗但牺牲速度，让“没有免费力量”成为选择，而不是单纯惩罚。

**升级**：价值越高，越被系统固定使用；资源获取与组织控制同步加深。

### ARC-V01-03 · 坏掉的虫种

约CH031—50。

**读者期待**：陈缺不再只查“虫为什么坏”，而开始第一次把自己在药圃获得的专业位置、配方知识和制度接口反过来用于争资源与安全空间。

**主要兑现**：
- 确认异常批次与衰竭灵脉产生的异常返灵/归息有关，只推进到第一卷允许层；
- 回收陈缺验虫针弱阳性的真实原因；
- 至少一次让白骨山自身的配方/记录/责任链成为陈缺的杠杆，而不是只给他新秘密；
- 获得资源、议价或行动权限上的一项实质提升。

**升级**：他越能解释问题，顾长槐等人越有理由把他卷进更核心的责任链。

### ARC-V01-04 · 内山的药

约CH051—75。

**读者期待**：第一次进入此前完全接触不到的资源与产业层，周玄伏笔正式兑现。

**主要兑现**：
- 周玄尸体用途回收；
- 展示成熟血虫 + 宿主的药材产业链；
- 陈缺因此前累计价值获得真实内山接触权限/任务，而不是靠巧合偷听；
- 资源与世界认知同时升级；
- 韩鸦受控背景推进，顾长槐中层压力具体化。

**升级**：陈缺第一次看见自己“有用”在更大供应链里意味着什么，也更难简单消失。

### ARC-V01-05 · 交药期

约CH076—100。

**读者期待**：陈缺从一直被别人交易、分类和处理的人，成长为能够参与交易、改变价格与条件的人。

**主要兑现**：
- 外部验收、批次问责、韩鸦脱控、赵石救人、陈缺离山目标形成多方博弈；
- 陈缺至少拥有一项别人必须认真考虑的交易筹码；
- 早期获得的药工价值、权限、记录与关系债集中产生效果。

**升级**：参与交易意味着必须承担选择谁、舍弃什么、暴露多少的现实责任。

### ARC-V01-06 · 离山

约CH101—125。

**读者期待**：第一卷长期压迫的集中释放——陈缺真正离开白骨山。

**主要兑现**：
- 利用制度矛盾、外部交易和自身药材价值获得出口；
- 白骨山为阻止/控制他付出真实制度或利益成本；
- 不靠低境界主角单人灭门；
- 真修、职业价值、身份、关系筹码和信息长期累计共同发挥作用。

**升级**：离开不是无敌自由，而是进入更大的正常修仙社会，并发现血虫不是修仙本身，真正修炼仍有资源成本。

## 使用规则

1. 每章起草前必须明确属于哪个 Arc，服务哪个卷级问题。
2. 每个 Arc 都必须明确“期待—兑现—升级”，但不得按固定章节频率机械制造高潮。
3. 章节可以偏离预定节点，但偏离后要更新 Arc，而不是偷偷让总纲失效。
4. 卷级终点和真相层级比具体章号更重要。
5. 当前卷以 `planning/volumes/V01_DETAIL.md` 为中层约束，短期仍以 `planning/ROLLING_OUTLINE.md` 和上一章因果为直接依据。
6. 任何新增大势力/大境界/世界级真相，必须检查 `canon/WORLD_BIBLE.md`、`canon/CULTIVATION_SYSTEM.md` 和 `planning/TRUTH_REVEAL_LADDER.md`。
7. 商业优化不允许覆盖 Canon，也不允许让人物为“爽点任务”降智；应选择更有情绪回报的合理因果。
