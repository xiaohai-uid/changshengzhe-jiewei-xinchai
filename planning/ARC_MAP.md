## Series · 《长生者皆为薪柴》

长期成长：

**发现规则 → 理解规则 → 利用规则 → 掌握力量 → 看见代价分配 → 修改局部规则 → 承担规则后果 → 追踪规则来源 → 建立新的偿还方式。**

商业节奏：**期待 → 兑现 → 升级**。不要求固定爆点频率，但禁止长期只用“新秘密/新危险”维持追读。

## Phase Map

### PHASE I · 我为什么会被吃（VOL01—VOL04）

从白骨山人体药材机制，推进到正常修仙、公共灵脉与古代循环失败。

阶段终点：天地回收不是人格化养殖阴谋；真正的问题开始转向“文明怎样分配成本”。

### PHASE II · 谁在替谁偿还（VOL05—VOL06）

从仙籍、配额与合法代偿进入不同文明的偿还方式，再直接进入归欠、长生盟与守衡派。

阶段终点：“长生者皆为薪柴”获得第一层完整意义。

### PHASE III · 能不能换一种还法（VOL07—VOL08）

界外代偿与天倾让旧账同时到期；陈缺从破解者转向制度设计者。

阶段终点：建立谁取谁偿、活着持续归还、不能无限外包的新秩序。

### ARC-V01-01 · 提前的七日考核

- **状态**：ACTIVE
- **范围**：CH001—约CH011/12
- **当前锚**：CH006末，陈缺与四名青绳新人被点往南二，其中包含韩鸦交易目标。
- **核心冲突**：异常血虫批次迫使白骨山提前分流；韩鸦交易、赵石药房后状态、交易目标逃亡准备与陈缺无虫真修首次真正碰撞。
- **当前正向期待**：陈缺能不能把青河县药铺本事变成一个白骨山“不愿轻易丢掉他”的用途。
- **Arc成功条件**：陈缺不再只是“骗过检查”，而获得“有用异常者”的组织价值、后续工作/资源接口与第一项耐久主动权。
- **Arc成本**：更深记录、更固定职责、更高监视。
- **禁止**：普通擂台、残余真气突然恢复、看多个样本后完美解题、主奖励再次只是知道秘密。

## 后续卷Arc原则

详细见 `planning/VOLUME_BLUEPRINTS.md`。这里仅锁三条：

1. 每卷至少完成一次真实处境翻转，而非只上升真相层级。
2. 同一个世界观结论不拆成两卷反复证明；理论、人物立场与后果优先在相邻Arc内完成闭环。
3. 如果实际正文比计划更快完成卷级问题，提前收卷；如果人物因果确实需要更多空间，可弹性增加少量章节，但超过全书约210万字前必须做Macro Drift Audit。

## 使用规则

1. 每章起草前明确所属Arc、当前正向期待、该章是否承担兑现。
2. 已发布正文 > Canon Core/World Bible > 当前状态 > 卷级终点 > 当前Arc > Rolling Outline > 早期章号计划。
3. 卷级终点比具体章号重要；章号只是容量提醒。
4. 任何新增大势力/大境界/世界级真相必须检查 World Bible、Cultivation System 与 Truth Reveal Ladder。
5. 200万版本优先回收旧承诺，不用新增谜题掩盖旧线。
