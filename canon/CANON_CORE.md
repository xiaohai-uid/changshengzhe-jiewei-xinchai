# CANON CORE

以下内容属于当前底层硬 Canon，除非出现明确逻辑冲突，否则不得轻易修改。

## 主角核心

陈缺，17岁，青河县药铺学徒出身，下品木灵根。谨慎、观察、风险意识强，擅长理解系统，但并非永远正确。

## 力量原则

所有力量必须存在来源、进入路径、使用代价与最终受益方；不存在真正免费的力量。

## 当前已公开的修炼层级

截至CH003，正文只向读者与陈缺明确到以下粗略顺序：

**引气 → 炼身 → 开府**

- 引气：将天地灵气真正引入体内，是踏入修行的第一步。
- 炼身：当前只知道位于引气之后、开府之前；完整能力、门槛与代价尚未展开。
- 开府：当前已知顾长槐处于这一层级，并能担任白骨山外山执事；陈缺只确认其远强于新人，不知道开府境的完整能力边界。
- 更高境界尚未在正文正式揭示，不得提前当作读者已知常识倾倒。

以后新境界首次进入正文时，必须让读者同时获得足以判断其相对高低、基本意义或现实地位的参照；禁止只丢境界名不给尺度。

## 白骨山血虫

血虫是白骨山人为加入修炼体系的养药机制。它不是所有修仙者的必需条件。修士可以通过其他方式真正修炼，但真正修炼本身也存在更深层代价。

## 长期命题

> 修士食天地。
> 天地亦食修士。

终极含义尚未完全向人物或读者揭示，不得提前一次性解释。

## 真相分层

陈缺目前已经确认白骨山以血虫培育新人作为人体药材；他尚未确认整个修仙文明都是养殖体系，只能对修炼本身可能存在的更深代价或系统性问题保持弱怀疑。

## Canon 原则

已发生正文事实优先于旧计划。任何反转应重新解释旧事实，而非无铺垫否定旧事实。
