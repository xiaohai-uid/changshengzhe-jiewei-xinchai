### 身体 / 真炼身工作假设

- CH019—20已经证明：真气经过真实劳损部位后会变薄，而恢复/耐劳变化比腹中真气更持久。
- CH021—22药房刻意把陈缺隔离出药圃三日：不碰活苗、不进后棚、药粥暂停，且陈缺无新截气/无残篇修炼。
- 三日内陈缺的腰腿/整体耐劳没有退回早期水平，证明既有身体变化至少具有**短期累计性**。
- 当前可确认：身体增长不是只跟腹中那一缕真气同生同灭。
- 仍UNKNOWN：真气如何固定在肉身、完整炼身机制、精确条件、正式破境标准。

### 当前真修资源层级

#### A. 活苗 / 活药
- 木气较稳，是已验证来源。
- 高风险：每株/每批都有损耗与责任，不可自由截取。

#### B. 刚剪青篓边损
- CH023亲证：刚离活株的断须仍有短暂木气窗口，之后快速衰散。
- 极微量可按残篇引入，但比活苗来源更散、更短，并可引发右臂近肘弯针痛。
- CH025进一步证明：从多株边损各取极微一丝可以合成极薄一层，但多来源气更难收束；一边工作一边压气会分神，陈缺险些把白篓完整根错分。
- 因此这是**潜在低单株损耗来源**，但效率低、注意力成本高、经络成本真实。

#### C. 保持湿润的西山青料
- 青篓边损并非无人管理：会被西山药渣棚收走，并要求保持湿润。
- CH024观察到黑陶壶苦腥液可重新浇湿青料；被保持湿润的断根残余木气比自然放干更久。
- CH025锁定隔夜青料不可擅自加渠水。
- 该物料属于明确生产链，有记录、有收料人、有未知用途；不能视为免费修炼资源。

#### D. 黑盆死透腐料
- 已腐烂/死透的烂根烂叶进入黑盆倒坑。
- 陈缺触碰时感不到木气；西山不要。

### 食物 / 成本

- 正式药工食额稳定；CH022后原有药粥份例恢复。
- 食物可以支撑劳动与部分真修成本，但不能消除真气衰减、饥饿与经络负担。

## 4. 身份 / 工作 / 监督

### 外棚
- 正式药圃外棚药工，持“外棚”木牌。
- 许管事原三畦基准仍在；但南坡当值的半日按正式规则从外棚工量中折除。

### 南坡“验”牌
- CH021七日底账产生现实后果：顾长槐批准三日借工到南坡，观察陈缺在离开药圃/暂停活苗与药粥后耐劳是否回落。

- 经陈缺手验过的药篓可单独留签；返潮/混料/错收可顺签追责。
- CH024首次周期验工已真实生效：陈缺验出一篓底部返软根，孙婆让整篓返工。
- 结论：陈缺从“异常但能干”被重新定价为更专业的生产用途；权限和责任同时升级。

## 11. CURRENT GOALS / DANGERS

### 陈缺当前目标
1. 把已成立的肉身累计性推进成更具体、可持续的能力，而不是继续只验证“有效”。
