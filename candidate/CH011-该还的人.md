# 《长生者皆为薪柴》

## 第十一章：该还的人

第四只废篓刚靠上西墙，门外终于传来脚步声。守门的灰衣弟子先抬了头，那脚步只有一个人的，比下去时慢，踩到最后几级石阶时还拖了一下。木闩刚抽开一半，老马便侧身挤进来，左边裤腿从膝盖往下全是湿泥，手掌也擦破了一块。

“关上。”他扶住门框喘了口气，“韩鸦还在下面。”

守门人把门重新顶死。老周从桌后站起来，先看了一眼老马身后：“人呢？”

“没带回来。”老马从怀里掏出一团沾泥的东西，扔到桌上，“这个找到了。”

东西在桌面滚了半圈才摊开，是一截青绳。陈缺离得近，看见绳结已经散了，一头磨得起毛，另一头却断得很齐，不像从腕上硬挣开的。老周捏住断口看了看，问：“哪儿找到的？”

“石槽后面那堆烂藤底下。”老马道，“我跟韩鸦先沿平时倒废料的路找。石槽那边没人，后面那片泥新翻过，青绳压在藤底下。再往外有几只脚印，到了乱石那儿就看不清了。”

“你腿怎么回事？”

“踩滑了，没断。”老马低头看了一眼，“韩鸦让我先回来，说西门继续封着，谁都别再放下去。他还在下面找。”

这一趟跟老马下去的青绳只有那个少年。绳是不是一定属于他，没人当场敢把话说死，可烂藤底下刚多出来这样一截东西，再把“走丢”当成唯一解释已经很勉强。老周没让陈缺落笔，只把青绳压到砚台旁边：“先放着。人没回来以前，那根筹也别收。”他说的是砚台边那根一直空着位置的湿木筹。

守门人问要不要再放两个人下去帮韩鸦。老马当场摇头：“他让我回来就是怕人越下越多。乱石那边本来就滑，下面再挤几个人，找没找到先不说，摔一个还得往上抬。”老周没坚持，只让守门人把木闩重新检查一遍。门板合得严实，下面偶尔有风从缝里钻上来，带着湿土和烂药的味道，却听不见人的动静。

西门继续封，墙边的废料却不会因为少了个人就停下来。四只废篓已经把原本留给外运的空地堵掉大半，第五只也快满了；先前还能靠墙挤一挤，现在谁也不知道韩鸦还要找多久。老周扫了一眼屋里，直接把人喊起来：“烂得最厉害的压实，新废料挪东头。能救的药离它们远点，别等门开了，药也全闷坏了。”

赵石和另一个新人先去抬最靠外的一只废篓。篓底早被药汁泡软，两人刚抬离地，竹篾便裂了一根，半篓黑褐色的烂叶从缝里漏出来，啪嗒啪嗒落在石板上，酸苦味一下散开。老周骂了声，让人拿木铲，屋里原本还盯着青绳的人也都散了。

陈缺被叫去搬桌上的木筹和小秤。他右臂抬不过肩，只能用左手抱，东西不重，走得却比平时慢。南二东头原本只晾半干的药，现在临时腾出两张竹席，旧席卷起来靠墙，新送来的灰叶草往里挪，废料压到另一侧，一时间连落脚的地方都要重新找。

一个负责铺席的少年鞋底沾了药汁，连滑两次，忍不住骂自己今天没穿那双破草鞋。旁边的人笑他那双鞋底早烂穿了，真穿来只会少一只鞋。老周隔着半间屋子听见了，让他们有嘴就拿来报数，别等药混了再说自己摔得冤。

陈缺把小秤放稳，回头时赵石正蹲在地上铲刚才漏出来的烂叶。他脸色不算好，额角全是汗，动作却没有停。两人抬篓经过时，赵石看见陈缺一直用左手，低声问了句：“还抬不起来？”陈缺试着动了一下右肩：“过肩不行。”赵石没劝他歇，只把原本准备递给他的篓把换给了另一个人。

早上送赵石来的灰衣弟子说过午后来领人，算时间已经不远；西门下面的事还没有结果，赵石这半日却是有准时辰的。陈缺本来还想问赵石回药房以后打算怎么办，话到了嘴边又没问。赵石自己未必知道，问出来除了让两个人都记住这件事，没别的用处。

老周把一捆木筹塞到陈缺手里：“东头今天全重记，废的、能用的分开。刚才搬乱了多少我不管，从现在开始别再混。”

陈缺接过木筹，跟着两篓药往东走，经过赵石身边时停了一下：“上午借工那一笔在册上，带你来的木签也添过字。”

赵石抬头看了他一眼，手里的木铲只停了一瞬：“我记得。”

陈缺没再说别的。南二能替赵石做的事情有限，但这半日不是白站在这里；若以后真有人说他干不了活，至少有一处记录不是这么写的。赵石把最后一点烂叶铲进篓里，起身继续搬东西，也没有追着陈缺问。

午时钟响的时候，东头刚重新分完第一批药。赵石把一只空篓推到墙边，站直后揉了揉腰；钟声才落下不久，南廊那边便来了人，还是早上送他过来的灰衣弟子。

那人进门先看见满地挪过的位置：“怎么搞成这样？”

“西门封了。”老周正在看一篓被踩碎的灰叶草，头也没抬，“你有事说事。”

灰衣弟子从袖里抽出那块薄木签：“来拿丙九十八。半日到了。”

赵石已经听见。他没等老周叫，先把手里的空篓放下，走到桌边。老周看了一眼那块木签：“我这里正缺人，再留半日。”

“早上说好的午后交。”灰衣弟子道，“药房已经催过一次。你要继续借，自己去跟那边说。”

老周今天连西门这笔账都没对上，显然不想为了一个临时抬篓的新人再往药房多认一层责任。他把木签推回去：“那带走。”

赵石却没有马上伸手。他看着木签边角早上添的那一笔，问：“师兄，这半日算我干过活吧？”

“废话。你没干我留你吃饭？”

“那劳烦再写清楚一点。”

送人的灰衣笑了一声：“你还挑上了？药房要的是你这个人，又不是你抬了几篓。”

“我知道。”赵石这次看向他，“所以才要写。”

他说完又对老周道：“今天回去以后，他们怎么处置我，我不知道。可这半日我抬了篓，也没倒在这里。以后要是有人说我干不了，南二得有这笔。”

老周盯了他几息。桌边那截青绳还沾着泥，西墙又堆着一排没法运出去的废料，他显然没耐心替赵石盘算以后，却也没有理由抹掉已经发生的事。最后他伸手：“笔。”

灰衣弟子把木签按在桌上，没有拦。对他来说，人按时带回去就够了，南二愿意多写几个字并不值得争。老周蘸了墨，先看一眼赵石，又问：“上午最重那几篓你抬过没有？”旁边一直跟赵石搭手的新人说抬过三趟，老周便低头写，没让赵石自己报数。

陈缺下意识往桌边走了一步，东头却有人在这时喊：“丙九十七，这两篓哪只算废的？”

两只刚搬来的篓子并排放着，一只上面压着断藤，另一只底下混了几把还能晾的灰叶。刚才搬东西的人急，原本插在篓沿上的木筹也掉了一根。若现在继续留在桌边，东头那边就会照着错的往下堆；老周才把这一块交给他，第一批就混起来，他在南二这两日积下来的“可用”经不起几次这种事。

赵石也朝东头看了一眼。那一眼很短，既没开口留陈缺，也没冲他摇头。

陈缺没有去接老周那支笔，只对赵石说：“借工那页有你的编号。木签带回去，别让他们只收人，不带这笔。”

“知道。”赵石点了一下头。

陈缺转身去了东头。那两篓药并不难分，断藤那只废得多，另一只只是搬乱了，底下还有一层能留。他蹲下来用左手翻了几把，让人把可用的重新铺开，又把掉在地上的木筹找回来，对着篓沿旧墨重新插好。右肩一直发紧，他没碰重篓，只负责把后面的东西分清。

桌边的说话声隔着半间屋子传来。老周嫌赵石麻烦，还是在木签背面添了几个字，写完又让旁边搭手的人看了一眼，免得以后有人说是赵石自己胡报；送人的灰衣催了两次，说药房那边不等。赵石临走前似乎又问了什么，声音被搬篓的响动盖过去，陈缺没有听清，也没有停下手里的活。

等东头第二批药送过来时，赵石已经走了。门口少了一双沾泥的鞋，他刚才用过的木铲靠在废篓旁边，铲面还粘着几片黑叶。有人顺手要把木铲拿去冲，老周看见后又骂了一句，说西门都堵成这样了还往地上泼水，那人只好拿破布把铲面擦了擦。

韩鸦仍没有回来。老马坐在门边给膝盖缠布，偶尔抬头听外面的动静；那截青绳一直压在砚台旁，泥水慢慢干成灰白色，旁边那根没有收回来的湿木筹也还在原处，谁都没把它补进盒里。

陈缺从东头回来交第一轮木筹时，赵石那条借工记录后已经多了一个勾。老周正低头核新挪过来的药数，没空解释木签上最后写了什么；西门的木闩仍横在门槽里，外面一直没有新的脚步声。
