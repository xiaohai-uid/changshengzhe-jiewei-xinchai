# CHAPTER GATE

> 每章必须依次通过 PREWRITE → PRECOMMIT → POSTCOMMIT。不是评分表，而是防连续性崩坏门禁。

## PREWRITE

写正文前确认：

1. **承接**：上一章最后一个实际动作/决定，最自然导致什么？
2. **合同**：本章最重要的一两件事是什么？哪些必须推进？哪些绝不能发生？
3. **角色知识**：出场角色是否可能使用自己不该拥有的信息？
4. **能力边界**：陈缺当前能做什么、不能做什么；任何新力量必须有来源与代价。
5. **重复破局**：最近章节是否已经使用过装弱、偷听、下药、假死、信息差、被抓谈条件等同类方法？
6. **活跃伏笔**：本章相关 FP / P / S 项有哪些？哪些只能推进证据，不能揭底？
7. **下章空间**：本章结尾要给下一步留下因果空间，但不强行制造悬崖。

任一项说不清，不直接起草。

## PRECOMMIT

正文完成后检查：

### 连续性
- 是否与 `main` 已发布正文、Chapter Ledger、Tracking State 冲突？
- 位置、伤势、道具、境界、时间是否连续？
- 配角行为是否符合自己的利益，而非只为陈缺送信息？

### 世界规则
- 新力量从哪里来？
- 如何进入使用者？
- 代价是什么？
- 最终谁获益？
- 如果答案未知，正文是否明确保持未知而非作者替角色下结论？

### 信息差
- 作者知道但读者不该知道的内容是否提前泄露？
- 读者知道但角色不知道的内容是否被角色越权使用？
- `SUSPECTS` 是否被误写成 `KNOWS`？

### 剧情质量
- 本章是否只有一两个核心功能，而非流水账？
- 是否至少有一次认知/关系/风险/能力的实质变化？
- 是否出现无代价成功或为爽点强行降低对手智商？

### Anti-AI
- 是否连续大量 5—15 字独立段？
- 同一动作是否被“发生→感知→身体反应”重复写三遍？
- 是否用“他感到/他意识到/他终于明白”替代可见证据？
- 是否大量使用万能比喻、空气凝固、心头一颤、深吸一口气等套话？
- 对话是否有角色差异，而非所有人都为解释设定服务？
- 章末是否出现总结、升华、哲理或“他不知道的是”式预告？

## POSTCOMMIT

章节被用户认可后才执行：

1. 正文进入 `main`。
2. 追加 `state/CHAPTER_LEDGER.md`，只写不可撤销事实。
3. 更新 `tracking/TRACKING_STATE.json`，`state_revision + 1`。
4. 更新 LIVE / KNOWLEDGE / RELATIONSHIP / PLOT 人类可读视图。
5. 更新 AUTHOR_TRUTH / READER_KNOWN；UNKNOWN 不得自行补全。
6. 新增 `tracking/chapter-records/CHxxx.md` 紧凑记录。
7. 重算 `planning/ROLLING_OUTLINE.md` 与 Context Card 下一章合同。
8. 每5章生成 Snapshot；每10章做 Continuity Audit。

只有 POSTCOMMIT 完成，下一章才视为可安全开始。
