## Effective after CH011

### 商业节奏

CH007—CH011已经形成：

1. 职业能力 → 工作入口；
2. 工作入口 → 有限执行边界/小资源；
3. 既有位置 → 改变赵石即时流转 + 改变自身二验处置；
4. 影响力 → 责任链；
5. 责任链遭遇真实事故后，陈缺的“可用”跨场地保留下来，但赵石与TARGET两条线都脱离了他能直接控制的范围。

因此CH012不能再只给“继续留用/继续观察”这种小升级。第一Arc必须把陈缺的累积工作价值换成更耐久的 **STATUS / RESOURCE INTERFACE / FREEDOM** 至少两项，同时留下更深控制成本。

### CH011实际模式记录

CH011由用户直接最终定稿，以下只用于未来防重复，不反向修改该章：

- 优点：动作后果迅速到场，南二从桌边流程转成黑水倒灌/搬迁；TARGET、赵石、韩鸦都有独立行动；TARGET状态实质推进；赵石时限真实兑现；陈缺伤势与真气限制保持。

- 分段/章尾：用户最终稿明确保留大量短段与“割断青绳”主题尾声；这是已发布文本，不反向修订。但从CH012起恢复FM-013/NAT-003与NAT-006正常检查，不能把CH011的特殊最终选择机械复制成新默认。
- 新空间机制“旧泄沟/第一道石界”已成为Canon，后续只能使用其已建立后果，不能为了追捕继续无限加第二、第三条秘密沟道。

### CH016—CH019 商业节奏

当前四章形成的递进不是“获得→清零”，而是：

1. **CH016：资源稳定后，陈缺第一次主动牺牲短期成长来管理暴露。**
2. **CH017：权限升级成专业判断，同时开始承担真实损耗。**
3. **CH018：主角线暂缓，让赵石用自己的算法完成阶段性生存兑现。**
4. **CH019：真炼身前置获得更强兑现，但增长立刻被工作系统吸收成工量，而非被惩罚性清零。**

情绪账户：总体为正。陈缺确实更能恢复、更能做活、拥有更稳定食额和后棚接口；代价主要是暴露/工量/责任扩大，而不是把资产拿走。

### Algorithm cooldown after CH019

短期已用算法：
- 主动压低可见增长 / 放弃已知有效修炼窗口（CH016）；
- 职业判断 + 自担损耗 + 保留未知反常单株（CH017）；
- 配角用额外劳动交换局部规则边界，主角最佳动作是不帮（CH018）；
- 自然纵向对照 + 极微三转后效 + 增长被生产系统立即吸收（CH019）。
