# CHAPTER TITLE STANDARD V2

## Purpose

章节名不是后台剧情摘要，也不是作者对本章主题的总结。

它首先是读者在目录、追更页和章末跳转处看到的**点击入口**。在不虚假、不剧透真正谜底的前提下，它应该让读者产生至少一个直接反应：

> “这是什么意思？” / “谁说的？” / “怎么会这样？” / “然后呢？”

## 2026-09-01 番茄高热样本校准

从番茄官方页面可见的高热作品目录看，强章名常见的不是“流程概括”，而是以下几类：

- 《十日终焉》：`空屋`、`说谎`、`灾难？`、`赢面`、`摊牌`、`结束了？`
- 《我不是戏神》：`我们在看着你`、`爸，我饿`、`第二只？`、`你也是个灾厄`、`准备好回答我的提问了吗？`
- 《天渊》：`了断因果，莫要后悔`、`我的去留，与你无关`、`收账`；近期还有`谈不拢，战！`、`围杀，灭口`、`给你一个机会`
- 《诡舍》：`无人的别墅区`、`肉没味`、`消失的尸体`、`带毛发的肉`、`可怕的三楼`

这些标题不代表本书要模仿其文风，但说明一个商业阅读事实：**标题先制造具体阅读欲，再承担概括功能。**

## Preferred title families

每章最终标题优先从以下六类中寻找，不要求每章同一种：

1. **异常事实**
   - 一个看起来“不该发生”的具体结果。
   - 例型：`昨天还抬不起来`、`死掉的气去哪了？`

2. **危险台词 / 人物原话**
   - 角色在真实利益冲突中说出的句子。
   - 优先保留人物声音，而不是作者润色成大道理。

3. **悬念问题**
   - 问题必须是读者本章真会追问的，不是虚构悬念。
   - 问号可以使用，但不可连续滥用。

4. **具体危险物 / 现场异常**
   - 物件本身就带异常：一截断绳、一只不该出现的手、变色的叶、被挪过的牌等。
   - 普通道具名若没有异常性，不够。

5. **结果先行**
   - 直接抛出本章最有冲击力的后果，但不泄露关键谜底。
   - 如“谈不拢，战！”一类结构，本质是先给情绪结果。

6. **反差 / 反常识句**
   - 前后信息天然冲突，让读者想知道原因。
   - 必须来自正文事实，不得硬造哲理。

## What we are banning as the default

以下句式不是绝对禁用，但从现在开始默认判弱，除非能证明有非常强的角色/情节价值：

- `先……`
- `这一……`
- `该……了`
- `……要还`
- `……不能……`
- `……才算……`
- 工作指令式：`先把人分开`、`好药不能当废料`
- 流程节点式：`先借半日`、`药圃第一天`、`开始炼身`
- 作者道理式：`借来的东西总要还`、`留得住才算自己的`

这些结构的问题不是“不文雅”，而是**太像作者给剧情打标签，没有迫使读者产生新的问题。**

## Our recent title failure pattern

近期标题：

- 《先把人分开》
- 《一篓坏药》
- 《好药不能当废料》
- 《先借半日》
- 《这笔账得有人认》
- 《这一畦归你》
- 《药也要吃》

其中个别标题与正文有双层含义，但整体连续出现“工作口吻 / 规则口吻 / 道理句”，目录层面的刺激度和差异度不足。

**以后不能因为标题“有双关”就自动判好。点击欲优先于作者自我解释。**

## Title generation workflow

### 1. 正文写完后再正式起名

Scene Card阶段只允许工作标题。最终标题必须从已经发生的正文里长出来。

### 2. 每章至少生成 8 个候选

至少覆盖三种不同标题家族，不允许只是同一句改词。

### 3. 五项打分（每项0/1）

- **CLICK**：单独放目录里，会不会让人想点？
- **SPECIFIC**：是否只能较自然地属于这一章，而不是任意修仙文？
- **VOICE**：是否有角色/情节声音，而不是作者工作语言？
- **FRESH**：与最近12章是否明显换了结构？
- **HONEST**：是否真实兑现，不虚假吊胃口、不剧透未知真相？

最终标题原则上至少 4/5；`CLICK=0` 或 `HONEST=0` 直接淘汰。

### 4. 目录测试

把最近12章标题和新标题排在一起看。

如果新标题看起来仍像：

> “第十四个项目节点”

而不是：

> “这里发生了什么？”

则重做。

### 5. 去解释测试

如果必须写一段作者说明才能证明标题有双关、有深意，标题默认失败。

好标题应该在正文结束后自行变重，不靠作者解释。

## Length

- 常见强区间：2—10个汉字。
- 角色台词/问句可放宽到 14—18 字，只要节奏强。
- 不为追求“短”删掉真正有吸引力的人物声音。

## Spoiler / clickbait boundary

允许更商业、更有冲击力；禁止虚假。

- 可以：`你的伤，好得太快了`
- 不可以：正文只出现怀疑，却标题写`顾长槐发现陈缺无虫修炼`

标题只能比正文更会选角度，不能比正文知道得更多。

## Publication hard gate

最终交稿前必须记录：

- 至少8个候选标题；
- 候选分别属于哪些标题家族；
- 五项评分；
- 最近12章目录对照；
- 最终标题为什么比“事件摘要型标题”更能制造阅读欲。
