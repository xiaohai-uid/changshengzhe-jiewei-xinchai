# EXPECTATION / PAYOFF GATE V2

> 目标：防止长篇陷入“压迫 → 更多秘密 → 新压迫”，保证读者持续感到主角在获得可累积主动权。
>
> 进入条件：Post-Draft Audit + Publication Gate均PASS，且candidate_revision_id一致。

## 0. 基本原则

采用：**期待 → 兑现 → 升级**。

- 期待：读者知道陈缺当前具体在争取什么；
- 兑现：前面承诺真实落地并留下残余；
- 升级：新冲突从已获得的东西长出来，而不是重置到原点。

核心约束：

> **代价可以污染爽点，但不能习惯性归零爽点。**

> **信息可以是奖励，但不能长期成为唯一奖励。**

本Gate必须使用Post-Draft Audit里的章初/章末资产Diff，不允许只凭“感觉挺爽”。

## 1. EXPECTATION CHECK

必须回答：
1. 本章/当前小周期，读者最希望陈缺得到、做到或改变什么？
2. 期待来自此前正文还是临时宣布？
3. 是否不仅仅是“别死 / 别暴露 / 看下一关”？
4. 如果本章不负责兑现，是否明显推进兑现条件？

连续只有负目标：REPLAN/REWRITE。

## 2. PAYOFF CHECK

检查以下资产变化：
- ABILITY
- RESOURCE
- STATUS
- FREEDOM
- LEVERAGE
- IMPACT
- INFORMATION

记录章初→章末变化，并引用正文证据。

INFORMATION可单独成为重要奖励，但不能长期连续成为主奖励。

## 3. DURABILITY CHECK

必须问：
1. 收益到章末还剩什么？
2. 新代价是否把收益完全抵消？
3. 收益消失时是否转化为另一项长期资产？
4. 最近两次重要兑现是否都“刚获得→立刻失去→回到原点”？

连续两次重大获得几乎完整抹掉，默认REWRITE；明确设计的重大失败Arc除外，但失败必须永久改变人物/关系/世界状态。

## 4. AGENCY CHECK

- 本章主要推进是否由陈缺选择触发？
- 完全被动是否有明确必要性并积累反制条件？
- 是否再次出现“看别人踩坑→完整理解→精准通过”？
- 是否只是换道具，本质仍“隐藏→误判→脱身”？

若连续两章主要只是旁观/记录/猜测，第三章原则上必须出现改变局面的选择。

## 5. REWARD VARIETY CHECK

检查最近3—5次主要兑现：
- 是否全是信息；
- 是否全是境界升级；
- 是否全是别人震惊；
- 是否全是隐藏成功；
- 是否全是免于惩罚。

本书优先轮换：规则反制 / 职业价值 / 能力实践 / 资源获得 / 身份变化 / 关系议价 / 情绪释放 / 真相回收。

## 6. COST CHECK

成功仍需成本，可来自：身体、资源、暴露、责任、记录控制、关系债、错误认知风险、新敌意。

但必须回答：

> 陈缺付完成本以后，是否仍比场景开始多了一点什么？

长期答案为“没有”：商业节奏FAIL。

## 7. CONFLICT UPGRADE CHECK

优先：
- 获得身份→新职责；
- 获得能力→新资源需求/暴露；
- 获得议价权→更危险交易；
- 知道规则→必须决定怎么使用。

避免：
- 刚拿到就无因被夺；
- 同一种检查换房间再做；
- 上章解决“会不会暴露”，下一章从零重复。

## 8. READER QUESTION TYPE

标记主驱动力：
- MYSTERY
- ACTION
- PAYOFF
- RELATIONSHIP
- GROWTH

允许MYSTERY很强，但连续三章只剩“想知道答案”而ACTION/PAYOFF/GROWTH不增强，触发商业节奏报警。

## 9. 禁止机械公式

不采用：三章一小爆、五章一大爆、固定字数高潮、每章打脸、每章升级、每章必须赢。

慢章/失败章/蓄压章允许存在，但必须服务清晰期待并在合理周期真实兑现。

## 10. 结论

只允许：
- PASS：进入Continuity Precommit；
- REWRITE：长期负收益、纯信息、主动性不足、兑现被归零或奖励重复；
- BLOCKED：当前Arc正向期待/阶段收益未设计清楚。

**Expectation/Payoff PASS仍禁止交用户。必须继续通过Continuity与FINAL_DELIVERY_GATE，且所有结果绑定同一revision。**
