# BOOK IDENTITY GATE V1

> 目的：防止章节“没有明显写坏”，却失去《长生者皆为薪柴》的书种辨识度。

## 核心测试

把人物名、地名、专有名词替换掉后，本章是否仍能明显看出它属于这本书，而不是任意种田修仙/苟道/职场修仙？

每章交稿前至少检查：

1. 本章是否明显承载“玄幻成长 / 生存博弈 / 规则破解 / 世界真相”中的至少两项，而非只做日常工作或微小技术优化？
2. 核心冲突是否只能由当前世界规则、人物历史与组织制度共同产生？若换一个普通修仙药田仍成立，默认需要重构。
3. 陈缺是否因为理解/怀疑某条规则而做出有现实风险的选择，而不是只观察、试验、得到小结论？
4. 章末变化是否推进长期主问题：力量从哪里来、如何进入、代价由谁承担、谁最终获益？不要求每章回答全部，但至少一项必须被新的正文事实推进。
5. 成长兑现是否足以改变下一章的行动可能，而不是只得到难以感知的数字级改善？

## 反例

- 药圃日常 + 偷一点灵气 + 胳膊多撑几息：即使连续性/分段全部PASS，BOOK IDENTITY仍可FAIL。
- 只靠换标题、加一句世界观总结、强插韩鸦/赵石/TARGET，不能修复Book Identity。

## 通过原则

Book Identity不是要求每章同时塞满四种体验。允许单章偏重其中两项，但核心事件必须与本书独有的“规则—代价—制度—成长”链条发生咬合。

若 BOOK IDENTITY = FAIL：结构性REWRITE，不做表面润色。
