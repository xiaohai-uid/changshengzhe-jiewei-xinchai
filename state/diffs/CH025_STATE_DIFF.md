# CH025 STATE DIFF · 《别让这筐死透了》

## Canon Horizon
CH024 → CH025

## 时间 / 位置
- CH024次日清晨起，主要位于药圃东棚；西山收青篓延误，赵石因湿车坏轴临时推空筐到药圃。

## 陈缺 / 真炼身资源
- 西山迟到导致青篓边根在药圃累积，陈缺首次尝试从多株刚剪下、确定属于边损的细根中分散极微取气。
- 不是完整三转：陈缺只用残篇前段把多缕散气往腹中轻引，半个时辰后勉强聚成极薄一层。
- 多来源断根之气比活木更散、更难收束；陈缺分神时右臂内侧出现针麻，并差点把一截应进白篓的完整侧根分错。
- 陈缺立即放弃继续补气，优先保证工作；因此确认“边损分散取气”可行但效率低、注意力成本高、存在经络/工作风险。
- 该来源不是免费资源：青篓有明确西山下游用途与保持湿润要求。

## 西山湿料规则
- 许管事明确收到过西山要求：隔夜青料只盖湿布，不能擅自加渠水。
- 赵石临时到药圃推空筐；其工作边界仍是避开湿货，满筐由药圃抬上车，出东棚后另有人接。
- 赵石右手仅碰到未新浇黑壶液、但覆盖隔夜边根的湿麻布，就出现较轻的手指僵紧反应；程度弱于此前湿渣车。
- 赵石KNOWS（工作经验）：干渣称重/装筐/外运；湿料是另一类活，有药房的人来收。他不知道完整机制。
- 赵石说“他们不怕湿料烂，怕它死透”；这是其基于西山工作观察的认知，不升级为作者层终极机制。
- 药圃区分：青篓装未完全坏死的边损，西山要；黑盆装已腐烂/死透且陈缺感不到木气的烂根烂叶，直接倒坑，西山不要。
- 西山瘦汉傍晚再次要求“别让这筐东西死透了”。

## Knowledge Diff
### 陈缺
- KNOWS：多株新鲜边损可分散提供极微木气，合并后可形成一层可感知真气，但比活木来源更散、更难收束。
- KNOWS：这种方法会占用工作注意力并带来针麻/错分风险，不能无代价并行。
- KNOWS：青篓未死透边损与黑盆已死透腐料被生产系统明确分开；只有前者送西山。
- KNOWS：赵石接触隔夜湿边根本身也会轻度发作，因此黑壶液不是唯一可能触发因素。
- SUSPECTS-STRONGER：赵石异常与“仍保留某种活性/被特殊保持的湿料”有关；具体是什么仍UNKNOWN。

## Relationship Diff
- 陈缺 ↔ 赵石：赵石以自身工作边界和实际反应提供有限新信息，并主动提醒陈缺“能不碰湿的就少碰”；两人信息交换加深但各自工作/生存路径仍独立。

## Plot Diff
- 真炼身资源线：ADVANCED / PARTIAL-PAYOFF；找到不必直接伤活苗的分散边损取气路径，但效率低、气散、分神且物料有下游所有权/用途，尚不安全可持续。
- 赵石湿渣线：ADVANCED；未加黑壶液的隔夜湿边根也能引发轻度右手反应，触发因素范围进一步收窄但未锁定。
- 西山湿料/边损用途线：PLANTED → ACTIVE；“保持不死透”成为可追踪的生产事实，最终用途UNKNOWN。
- 正式炼身突破：仍未发生。

## Next Causal Hook
- CH026不应继续连查湿料或立刻追黑壶谜底；更自然的是让陈缺处理已经成立的资源闭环：如何在不破坏药材、不抢西山用途、不影响工作判断的前提下，把零散木气转成可持续身体增长，并产生一次更具体的能力兑现或代价。
