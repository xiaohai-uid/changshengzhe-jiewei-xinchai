# CH018 STATE DIFF · 《这车，我不碰》

## Canon Horizon
CH017 → CH018

## 时间 / 位置
- 承接CH017次日清晨。
- 前半位于药圃东畦沟尾；中后段位于西山药渣棚。

## 陈缺

### 青签苗结算
- 七株浅青竹签残苗次晨结果：**两株死亡，五株存活**。
- 昨夜最蔫的一株反而缓回一口气；一株昨日看起来较齐整的苗根颈腐坏死亡，另一株半边根团发黑软烂。
- 陈缺主动将两株死苗与对应青签摆出，没有掩埋损耗。
- 许管事按事实记录“昨日七株，今日剩五”；这是陈缺成为正式药工后的第一笔挑苗损耗。

### 药渣棚流转
- 陈缺按CH017安排，将青须草修根废料送往西山药渣棚，并等待/领取空篓。
- 第一次实际进入药渣棚，看到湿渣、干渣、晒席、排药沟/泥池与不同粗使工种的真实生产流转。
- 在等待空篓期间自然遇见赵石，没有主动去找赵石汇报或探问。

### 对赵石的可见观察
- 赵石三日试用期间仍右手/右腕不稳，会通过左肩、左臂、腰背和把小臂压在工具上来补足右手缺失的力量。
- 药房方向一辆装有四只铁箍深桶的湿药渣车进入棚内，苦腥气与CH015药房偏院闻到的气味高度相似。
- 随湿渣车靠近、桶盖被掀开，赵石右腕发生强烈不受控抽搐，铁铲脱手，脸色明显变差。
- 陈缺只能确认该湿渣车/苦腥刺激与赵石症状高度相关；桶内真实成分、虫体状态、机制仍 UNKNOWN。

### 对赵石选择的处理
- 赵石公开拒绝接触湿渣车：“这车，我不碰。”
- 陈缺没有上前帮赵石搬西坡干渣，因为那会削弱赵石向药渣棚证明“自己能独立完成替代工量”的现实筹码。
- 两人短暂低声交谈；赵石明确说自己不知道桶内是什么，也不想知道，只需要知道哪些气味要避开；若被送回药房，会再想办法。

## 赵石

### 身体
- 右手异常持续存在，平时重活下可通过身体其他部位补偿完成劳动。
- 湿药渣车/苦腥气刺激下症状显著加剧，达到铁铲脱手程度。
- 不能据此确认“湿药渣就是黑陶罐内容物”或任何具体成分，只能确认高度相关刺激现象。

### 主体选择 / 工作状态
- 面对跛脚老工要求卸湿渣车，赵石明确拒绝碰该车。
- 主动提出替代：不参与湿渣车卸载，但承担西坡剩余大量干药渣，按更重工量补足缺口。
- 不以“残疾”请求减工，而是用可完成的重劳动交换避开明确触发物。
- 药房查验人员在三日试用到期时根据跛脚老工记录与现场劳动结果决定：**先留在药渣棚**。
- 新条件：可以避开会诱发症状的湿渣车，但少掉的工量必须用其他苦力补足；若以后连其他重活也做不了，则回药房/偏院。
- 药渣棚仍属药房控制体系，赵石没有获得自由身份。

## 跛脚老工 / 药房查验人员
- 跛脚老工以生产能力为判断核心，承认赵石症状在湿渣车到场时明显发作，同时认可其平时重活产出。
- 药房查验人员依据三日工作记录与现场表现决定“先留”，但没有解除失败回收条件。

## Knowledge Diff

### 陈缺
- KNOWS：赵石在普通干渣重活中可以依靠左侧身体与姿势补偿右手问题。
- KNOWS：药房湿渣车/苦腥气靠近时，赵石右手症状会显著恶化到工具脱手。
- KNOWS：赵石本人也不知道/至少明确声称不知道桶内具体是什么，并选择先规避而非追根究底。
- KNOWS：赵石三日药渣棚试用结束后被允许“先留”，但要用额外其他工量补足自己避开的湿渣车工作。
- UNKNOWN：湿渣桶真实成分、与CH015黑陶罐是否同物、赵石体内血虫/药房处置完整机制。

### 赵石
- KNOWS：湿渣车相关气味/物会强烈诱发自己右手异常；知道避开它能保留其他劳动能力。
- BELIEVES/WORKING RULE：不必先弄清成分，只要能识别并避开触发环境，就能争取留在外侧工作。

## Relationship Diff
- 陈缺 ↔ 赵石：互助关系进一步表现为“尊重对方自己的求生方案”；陈缺明知帮忙能减轻赵石负担，却因会损害其试用证明而选择不插手。
- 赵石 ↔ 药渣棚：三日试用 → 有条件留用；价值来自实际重劳动，不是同情或保护。
- 赵石 ↔ 药房：仍受控制，但从“试用失败即回收”推进为“可持续以替代工量换取避开特定刺激物”的暂时位置。

## Plot Diff
- FP-005 赵石药房后果：ADVANCED → **PARTIAL-PAYOFF**；三日药渣棚试用完成阶段结算，赵石暂时留在外侧，但身体异常与触发源仍未解决。
- FP-008 血虫/药房异常：ADVANCED；湿渣车再次提供可重复刺激证据，根因仍保护。
- 陈缺—赵石关系线：ADVANCED；陈缺不替赵石解决，赵石以自身工作价值换生路。
- 药圃—药渣棚生产流转：PLANTED/ESTABLISHED；两处通过废料与空篓形成正常物流接口。

## Next Causal Hook
