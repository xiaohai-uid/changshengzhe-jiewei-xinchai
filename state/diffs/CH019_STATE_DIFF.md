# CH019 STATE DIFF · 《干得快，就再多干一畦》

## Canon Horizon
CH018 → CH019

## 时间 / 位置
- 承接CH018陈缺从西山药渣棚返回药圃后的当日下午。
- 主要场景位于药圃后棚/浅槽、外棚住处与水渠。
- 章节跨越两个夜晚并推进到第二个次日清晨/上午。

## 陈缺

### 工作 / 权限
- 许管事把CH017退下来的后棚缓苗交给陈缺参与日常翻看、松泥、修烂根、扶叶和遮帘管理。
- CH017那株“木气最盛但现在不值东畦”的青须草幼苗已被栽在后棚最外侧浅槽，仍健康存活，木气比此前更旺，苦涩药味仍淡。
- 后棚并非无人管的废料区；退苗仍按批次木签管理，完全死透才拔，其余尽量保留，未来仍可能再筛。
- 陈缺因此获得更稳定接触后棚活苗的工作接口，但同样承担其损耗责任，不能视为无主资源。

### 食物 / 资源
- 当日午饭为一块粗面饼与一碗稀粥，无药粥；正式药工食额能压下一部分高劳动后的饥饿，但不能完全消除。
- 第二次夜间三转前，陈缺先吃掉晚饭留下的半块饼并喝水；三转后出现饥饿时还能继续以剩余食物补充，没有再只靠冷水硬顶。
- 稳定食额进一步成为低效真修/身体恢复循环中的现实支撑资源。

### 暴露管理 / 第一个夜晚
- 陈缺明确意识到右臂每日被许管事记录，继续把所有变化堆在右臂会加剧暴露。
- 后棚半蹲劳动自然造成腰、腿的明显普通劳损；陈缺没有刻意制造伤势。
- 当日面对后棚旺木气幼苗，陈缺仍选择不截气；当夜没有运转《盗气残篇》。
- 次日清晨腰腿仍按普通劳损方式疼痛，只比夜里自然松缓一点；这成为对照证据：此前右臂/前臂较快改善不能仅以睡一夜解释。

### 第二次工作日 / 微量截气
- 第二日后棚工作量继续增加，腰腿再次形成真实劳损。
- 傍晚放水时，陈缺从那株旺木气、仍苦味淡的后棚青须草上只截取极少一缕木气，比此前东畦微截更少；立即停手，没有第二次截取。
- 当时青苗叶片、水珠等没有出现即时可见变化；长期影响仍 UNKNOWN。

### 三转 / 肉身变化
- 当夜严格按《盗气残篇》既有路线三转而止，没有新增口诀或改变路线。
- 真气经过右肩时只有轻微滞涩；经过白日劳损最明显的后腰与两侧大腿时明显变薄，后腰/腿根留下酸热。
- 三转结束后小腹真气逐渐难以感知，但腰腿酸热继续存在。
- 次日清晨，大腿根与后腰的普通劳损恢复明显快于前一次“只睡一夜”的对照：仍酸、仍累，但站起和伸直时的滞涩显著减少。
- NEW STRONGER EVIDENCE：真气三转后的持久变化不再只出现在旧伤右臂，也可出现在**当日真实劳损的腰腿部位**。
- 仍不得确认完整炼身机制；只能把“真气可能在受负荷/劳损部位被消耗并留下更持久恢复变化”从弱假设推进为更强工作假设。
- 未正式突破炼身境，无战斗能力跃迁。

### 公开右臂状态
- 右臂对外仍维持过肩约半寸、仍疼的状态，没有继续显著抬高。
- 许管事观察到恢复速度慢下来，评价“这样才像养伤”；陈缺对公开恢复曲线的主动管理暂时奏效。

### 新成本：能力被生产系统立即吸收
- 次日后棚劳动中，陈缺因腰腿恢复更快、耐力提高，比前一日更快完成两排浅槽。
- 陈缺意识到“不能再快”时已被许管事看到。
- 许管事没有追问原因，直接把后棚更里面**又一整畦/一片浅槽**交给陈缺继续处理。
- 一名老药工直白指出：“现在知道为什么我们干活从来不快了？”
- 新增长不是被清零，而是立刻转化为更高劳动要求与更高可见产出。

## 许管事
- 继续以生产效率/损耗而非修炼解释看待陈缺。
- 右臂恢复放慢后认为“像养伤”，暂未因此升级药房风险。
- 发现陈缺后棚工作速度明显提高后，不询问机制，直接增加其工作区域。

## Knowledge Diff

### 陈缺
- KNOWS：普通腰腿劳损在不运气时只按普通休息速度缓解；与此前真气介入后的恢复表现不同。
- KNOWS-PARTIAL：三转真气会在当日真实劳损的腰腿部位出现变薄/滞涩，同时这些部位的酸热与次晨恢复优势持续得更久。
- SUSPECTS-STRONGER：真气可能并非只作用于旧伤，而会在承受真实负荷的肉身部位被消耗并留下较持久变化。
- KNOWS：把公开右臂恢复速度压慢可以让许管事更容易按正常养伤解释。
- KNOWS：身体效率提高会直接被药圃转化成更多工作量，因此“变强”同时会扩大劳动责任和被观察的产出差。
- UNKNOWN：完整炼身法、真气固定肉身的精确机制、后棚旺木气幼苗被微截后的长期药性/生长影响。

## Relationship Diff
- 陈缺 ↔ 许管事：生产关系进一步加深；许管事把陈缺视为可扩量使用的正式药工，工作效率一提高便扩大任务，不形成保护或师徒关系。
- 陈缺 ↔ 普通药工：出现“老工刻意不干太快”的现实劳动经验提示，但没有形成新的重要关系债。

## Plot Diff
- 真炼身/身体承载线：ADVANCED SIGNIFICANTLY；三转后的持久变化从受伤右臂扩展到普通劳动造成的腰腿劳损，形成第一条更通用的身体承载证据。
- 食物→真修成本线：ADVANCED；稳定药工食额开始实际支撑三转后的饥饿与恢复成本。
- 真修资源线：ADVANCED；陈缺第一次从后棚旺木气、当前未进东畦的活苗进行极微截取，但长期植物损耗仍未知。
- 七日连续观察线：ADVANCED；右臂公开恢复曲线暂时被压到更像正常养伤，但一般劳动效率开始成为新的可见异常面。
- 药圃职业价值线：ADVANCED + COST；更高工作效率立刻换来新增一整片后棚任务。
- 药材价值规则线：保持ACTIVE；旺木气幼苗仍苦味淡、继续在后棚缓养，尚未完成价值机制解释。

## Next Causal Hook
陈缺已经获得“稳定食额 + 活木微量木气 + 真实劳动劳损 + 三转后更快恢复”的第一条低效闭环证据，但增长开始从右臂转移成更难隐藏的**整体工作效率**。下一章最自然的压力不是重复一次三转，而是处理：后棚旺木气幼苗若开始接近再次筛选，陈缺是否还敢继续把它当资源；以及七日连续记录逐渐逼近时，许管事会如何记录“胳膊没快多少，人却越来越能干活”这一新反差。
