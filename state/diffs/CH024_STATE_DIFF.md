# CH024 STATE DIFF · 《雨水没这个味》

## Canon Horizon
CH023 → CH024

## 时间 / 位置
- 三日后午后，陈缺第一次按“验”牌回南坡半日；次日上午又回药圃东棚。

## 南坡 / 西山湿料
- 西山青篓湿料短暂停在南坡阴棚；外观包含细须、断根、伤叶、发黑侧根等，与药圃青篓边损相符。
- 西山瘦汉以黑陶壶中的液体重新浇湿麻布；液体带明显苦腥味，和普通雨水/渠水气味不同。
- 重新浸湿的断根仍保留可感知的微弱木气，明显强于自然放干后的边根。
- 孙婆确认西山长期收取药圃割下、药房煮剩、前库退回等“能湿的”边料；白签成药去前库，青料去西山，各有记录。
- 陈缺手背沾到少量黑壶湿料液后仅有轻微发涩/紧绷，无右臂异常、无虫性反应。

## 陈缺认知
- KNOWS：黑陶壶湿料液不是普通雨水；青料保持湿润存在额外处理，而非单纯防晒。
- KNOWS：西山湿料中至少一部分来自药圃青篓边损，且重新浸湿可让残余木气留得更久。
- SUSPECTS-STRONGER：赵石右手异常的触发条件不应简单概括为“湿”；苦腥处理液/被处理湿料可能是更具体因素。
- UNKNOWN：黑陶壶液体成分、湿料最终用途、其与赵石血虫/经络损伤的完整关系。

## 南坡验工
- 陈缺独立验出一篓底层返软根，孙婆按生产规则整篓返工，并按签数调整；新验工权限产生真实责任和结果。
- 西山瘦汉面对陈缺追问只说“西山的活，少问”，未提供机制答案。

## Plot Diff
- 赵石湿渣线：ADVANCED；触发物范围从“湿渣车”进一步收窄为“西山特殊湿料/苦腥处理”，但仍未确认具体成分。
- 真炼身资源线：ADVANCED；确认保持湿润可延缓断根木气衰散，但该物料有明确西山控制与未知风险。
- 南坡验工线：ACTIVE；首次周期性当值真实发生，并通过返软根返工证明职责不是名义权限。

## Next Causal Hook
- 最自然下一步不是偷取黑壶液或立刻追问机制，而是利用现有药圃生产流程确认：青篓边损能否作为分散取气来源，以及“保持不死透”的下游要求会不会限制这条路。
