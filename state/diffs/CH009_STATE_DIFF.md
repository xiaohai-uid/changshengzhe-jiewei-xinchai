- 位置：章末回到白骨山外山南二，坐回记数/木筹桌边。
- 身体：右臂/经络伤势延续；普通外敷伤膏仅缓解表层紧绷，手仍抬不到肩高。CH009没有再次补药，也没有恢复真木属灵气。

- 工作资产：南二工作入口继续有效；本章开始承担木筹/废料记录，桌边位置与实际册籍记录功能进一步坐实。
- 外部影响：在赵石主动争取工作后，陈缺只提供自己亲眼知道的“昨日背过石头、走得动”这一事实，帮助老周把赵石从当前药房方向流转中借到南二半日；这是陈缺第一次让自己累积的组织位置改变另一个人的即时制度去向。
- 成本：陈缺与赵石的关联被南二/带队灰衣进一步看见；二验异常被更精确记录；去二验使陈缺失去一段对TARGET-0001的观察窗口。
- 当前新增风险：TARGET-0001在陈缺离开南二期间随老马抬废料从西侧门下去；老马已返回，而TARGET截至章末尚未按同伴时间返回。是否逃脱成功 UNKNOWN。

## 赵石

- CH009重新进入正文：与三名有特殊记号的新人被灰衣弟子带到南二门口附近；带队人口头说明其中两人送药房、一个去南三、一个等人来领，并当场指出赵石属于送药房的两人之一。
- 赵石自身目标延续：明确不愿回药房；看到南二缺搬运人手后主动上前说“我能抬”，并亲自抬起中等竹篓证明可用，不等待陈缺替他开口。
- 现实处置：老周因南二缺两名搬运人，承担责任将赵石“借半日”，午后再交回；赵石章末仍在南二工作，午后最终处置未发生。
- 身体：能完成中等强度搬运，但额头出汗、脸色一般；白绳仍在，绳结被墨染黑；袖口下暗红环痕仍存在。没有新增超常能力或完整恢复。
- 新记录：南二借工被写入木筹/册面体系；这不是自由，也没有解除药房方向的原有点名。

## 南二 / 二验制度

- 南二的现实用工需求可以暂时改变部分新人流转：老周以“南二缺手”为理由承担半日借工责任。
- 陈缺的南二留用记录已经进入二验人员参考信息，并实际影响即时处置：异常未解除，但组织选择暂留工作、三日复验，而非立即改道。
- “有用”开始成为制度计算变量，但并非免检/自由卡；异常记录更深、复验更明确。
