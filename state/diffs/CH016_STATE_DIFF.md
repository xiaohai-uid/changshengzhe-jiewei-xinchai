# CH016 STATE DIFF · 《我就给你单开一行》

## Canon Horizon
CH015 → CH016

## 时间 / 位置
- 承接CH015正式药工身份落地后的当日下午，并推进到次日清晨。
- 陈缺始终位于药圃外棚/东畦一带。

## 陈缺

### 工作 / 身份
- 第一次按正式药工工作量参与东边三畦新苗入圃前的湿土转运与铺整。
- 因右臂仍不能稳定负重，继续以半桶湿土为单次负荷；用更多往返次数补足总工量。
- 正式食额第一次明确改变其持续劳动能力：中午新增面饼与药粥使其在高频往返后仍能维持体力，没有迅速出现此前真修后的灼烧式急饿。
- 次日清晨仍主动维持半桶负荷，没有把实际可增加的重量表现出来。

### 身体
- 右臂公开抬举高度维持在过肩约半寸，肩后仍有真实疼痛。
- NEW：在相同公开活动幅度下，右手/前臂重复使用耐力与酸痛后恢复能力较前一日提升；能更久扶桶绳并在短暂松手后重新抓稳。
- 许管事现场确认并记录：“举得没多，倒是耐用些了。”
- 本章没有正式炼身突破、没有战斗能力增长。

### 修炼选择 / 暴露管理
- 傍晚放水时，陈缺明知青须草根部木气活跃，仍主动不截取任何木气。
- 当夜具备食物、身体与活药条件，却主动合上《盗气残篇》，选择“今天不练”。
- 这是第一次明确为控制公开恢复曲线而牺牲近期修炼速度；损失是真实可用的一夜成长机会。
- 次日仍不通过突然加重负荷展示身体进步，使公开恢复维持可解释范围。

### 新权限 / 资源接口
- 东边新苗抵达后，许管事把一小串头部染浅青色的竹签交给陈缺。
- 许管事安排其午饭后参与新苗分棚/挑苗；这是正式药工身份带来的新增工作权限，不是私人奖励。

## 许管事
- 继续按实际生产能力和伤势表现记录陈缺，不替其遮掩，也不主动深究恢复来源。
- 明确注意到“抬举高度没增、耐用性却提升”的变化，并将其写入正式药工记录。
- 在确认陈缺懂药且已是正式药工后，将新苗分棚工作交给他参与。
