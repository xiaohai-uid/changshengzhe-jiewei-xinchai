# CH017 STATE DIFF · 《现在不值这块地》

## Canon Horizon
CH016 → CH017

## 时间 / 位置
- 承接CH016新苗抵达后的当日下午。
- 主要场景位于药圃东棚、东边新畦与后棚方向。

## 陈缺

### 工作 / 权限
- 第一次以正式药工身份参与新到青须草幼苗的实际分棚与去留判断。
- 延续青河县药铺经验：通过泥气、根颈硬软、擦伤颜色、腐酸与草药气味判断苗根状态；遇到拿不准的仍交许管事确认。
- 从原本准备丢弃的残苗中保留七株自己判断“根未烂、仍可能缓活”的苗，并为其插上浅青竹签。
- 七株被单独栽在东畦沟尾的边角位置；许管事明确说明，次日死亡会记入陈缺的正式药工损耗记录。

### 新证据：木气与当前药圃价值并不完全同步
- 陈缺接触一株外观挺拔、根须完整、无腐坏、且自身可感木气明显旺于周边幼苗的青须草。
- 该苗草腥很重，但青须草应有的沉厚苦涩很淡；陈缺判断其“太生”，没有落青签。
- 许管事尝过侧根后将其放回原篓，并明确说：“它现在，不值这块地。”
- 该苗并未被废弃：许管事后续确认无病无烂的退苗会留在后棚阴生处缓养，三五日后再筛。
- 陈缺由此只能确认：**自己感知到的草木生机/木气旺盛，与药圃当下是否让一株苗占用东畦肥土，不是同一个判断。**
- 具体计价标准、药性形成机制、木气与药性关系仍 UNKNOWN，不得升级成“两套完整价值体系”或完整药理答案。

### 修炼选择
- 陈缺意识到那株被退回后棚的旺木气幼苗对自己可能是优质截气对象，但没有当晚去后棚掀布或截取。
- 原因不是放弃资源，而是证据不足：该苗仍会继续被养并可能数日后重新筛选，贸然截气可能改变其未来状态并形成不可见损耗。
- 本章没有新增真气摄入、三转或炼身突破。

## 许管事
- 对陈缺的药材判断只做必要纠正，不承担系统讲解职责。
- 允许陈缺为自己保留的七株残苗承担次日损耗结果，形成“权限=责任”的正式药工逻辑。
- 对旺盛但“太生”的苗选择继续缓养而非废弃，说明药圃会按未来可用性继续配置资源，但完整标准未解释。
- 章末安排陈缺次日将修根废料送往西山药渣棚，并带空篓回来。

## Knowledge Diff

### 陈缺
- KNOWS：一株植物“活得旺/木气旺”并不自动等于“现在值得进入东畦”。
- KNOWS：至少部分被当下退下的健康苗并不会立刻废弃，而会继续缓养、之后再筛。
- KNOWS：自己用青签保下的苗若次日死亡，正式损耗会记到自己名下。
- SUSPECTS：药圃对青须草的价值判断还包含自己目前不完全理解的药性/成熟程度因素。
- UNKNOWN：木气、药性、成熟度之间的完整关系；不得确认“木气越少药性越高”或其他单向规律。

## Relationship Diff
- 陈缺 ↔ 许管事：陈缺开始被当作可以承担低阶药苗判断与损耗责任的正式药工；许管事提供有限纠正和结果约束，不导师化。
- 陈缺 ↔ 其他药工：出现普通工作摩擦/嘲笑，陈缺没有靠身份压人，仍以实际判断和第二天结果承担后果。

## Plot Diff
- 药圃职业价值线：ADVANCED；陈缺从普通养护/搬运进入低阶苗情判断与损耗责任。
- 药材价值规则线：PLANTED → ADVANCED；出现“木气/生机旺盛但当前不值东畦”的纵向证据，完整机制仍保护。
- 真修资源线：ADVANCED-SLIGHTLY；后棚中存在木气旺盛、但当前未进东畦的活苗类别，陈缺暂未利用。
- 真炼身线：本章不推进实验，保持既有假设。
