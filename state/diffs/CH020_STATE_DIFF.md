# CH020 STATE DIFF · 《这点力气，已经记进去了》

## Canon Horizon
CH019 → CH020

## 时间 / 位置
- 承接CH019章末同一工作日上午，推进至当日晚间。
- 陈缺主要位于药圃后棚、东畦与外棚水渠一带。

## 陈缺

### 身体 / 工作能力
- 右臂公开表现仍控制在“过肩约半寸”，未出现新的公开抬举台阶。
- 腰腿在此前微量真气三转后的恢复优势继续转化为真实劳动结果：同样半日内可处理更多浅槽/药畦，僵滞感较前日减轻。
- 变化不是突然获得蛮力，而是重复劳动耐受、恢复和持续工作能力提高。
- 许管事据实际工量把陈缺次日派工基准从约两畦半提高到三畦；成长第一次明确被组织直接折算为新增劳动义务。

### 暴露管理
- 陈缺主动放慢第三畦进度，但仍无法抹去此前已经形成的工量记录。
- KNOWS：只压低右臂公开恢复不足以隐藏身体变化；劳动产出本身会把分散到腰腿/全身的成长重新聚合成可追踪记录。
- 本章没有新增截气或夜间三转，没有正式炼身突破。

### 药材认知
- 后棚此前“木气旺但不值东畦”的青须草，经过约三日缓养后木气较峰值略收敛，根部苦味/药性表现却明显加深。
- 许管事判断其已从“草”变成“药”，并将其连同另两株迁入东畦。
- 另有一株枝叶旺、木气较盛的苗因根味不足被许管事评价为“白长肉”，继续留后棚。
- 陈缺由可见事实确认：自己感知到的草木木气强弱，与白骨山当前判断的药材价值/药性并非同步指标；两者甚至可短期反向变化。
- 不升级：陈缺仍不知道药性形成的完整机制、东畦计价公式、木气究竟流向何处，也不能确认“木气转化成药性”。

### 七日记录 / 当前危险
- 当晚一名陈缺未见过的灰衣药房弟子到外棚收取“七日底账”。
- 该弟子查看陈缺记录时注意到：右臂公开恢复停滞，但腰腿耐劳与实际工量持续上升。
- 许管事以“伤的是膀子、腿腰还能干”为生产层解释，没有替陈缺虚造伤情，也没有给出真修解释。
- 其他人员记录被收入竹筒，陈缺的记录被该灰衣弟子单独扣在掌中带走。
- 章末陈缺确认：自己虽然压住右臂恢复曲线，但全身劳动能力已经形成另一条可见异常轨迹。

## 许管事
- 继续按实际产出派工，明确把陈缺新增耐力转化为次日三畦任务。
- 通过口尝根须/长期药圃经验判断缓苗药性是否成熟，并把三株苗迁入东畦。
- 面对药房弟子追问时只提供自己能观察到的事实，不主动替陈缺解释异常来源。
- 对陈缺仍是生产关系：能干就加活，药材值钱就提高责任，不构成私人保护。

## 新灰衣药房弟子
- 身份：药房体系灰衣弟子；姓名、境界、具体职司 UNKNOWN。
- 行动：到外棚收取七日底账；对大部分记录快速归筒，对陈缺记录停留更久并单独带走。
- KNOWS：至少知道陈缺公开记录中“右臂恢复停滞但腰腿耐劳/工量上升”的异常组合。
- UNKNOWN：为何单独扣下、将交给谁、是否已经形成明确怀疑、后续处置。

## Knowledge Diff

### 陈缺
- KNOWS：公开能力不只通过伤势检查暴露，也会通过持续工量被记录。
- KNOWS：木气强弱与当前药性/药材价值不是同一指标。
- SUSPECTS：药房可能会因为“局部伤势未快、整体耐劳却持续增加”的记录进一步关注自己。
- UNKNOWN：灰衣弟子单独带走记录的具体目的与下一步处置。

## Relationship Diff
- 陈缺 ↔ 许管事：生产绑定进一步加深；许管事会把成长直接换算成更高工量，同时仍按事实为其向药房描述伤势与劳动表现。
- 陈缺 ↔ 药房体系：七日观察从“药圃本地记录”推进为“记录已被药房实际收走并单独筛出”，监督压力升级。

## Plot Diff
- 真炼身/身体承载线：ADVANCED；成长从右臂局部扩展为腰腿与整体劳动耐受的持续性收益。
- 七日连续观察线：ADVANCED / IMMINENT；记录周期完成一次实质上报，且陈缺记录被单独抽出。
- 药圃职业价值线：ADVANCED + COST；生产效率提升带来明确新增工量，不是免费收益。
- 药材价值规则线：ADVANCED；首次确认木气强度与药性/价值不能直接等同，缓养过程会改变二者关系。
- 正式炼身突破：仍未发生。
