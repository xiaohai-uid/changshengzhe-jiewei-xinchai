## 陈缺

### 位置 / 工作
- 继续位于药圃外棚。
- 正式完成三日候工的第一整日工作。
- 负责的最外侧青须草药畦因前夜踩踏导致表湿里硬、十余株发软。
- 陈缺通过松土、减缓水势与扶苗保住大部分药苗；仅确认一株根颈发黑死亡。
- 许管事没有拔掉“丙九十七”畦牌，明确让其“明天继续”。候工位置保留。

### 新人物接口
- NEW：外棚瘦汉被其他药工称为“许管事”；陈缺由现场称呼获知姓氏/职务称呼。
- 许管事以药苗存活、损耗与工作结果为核心，不知道陈缺的无虫真修。

### 真修 / 规则认知
- 陈缺观察到：青须草在浇水后，木性灵机的明显变化先从根边出现，再向叶柄与叶片扩散。
- KNOWS：草中木气不是固定不动的一团；至少部分木气会随根部吸收过程发生可观察的流动。
- UNKNOWN：这股木气究竟来自水、土、地脉还是其他来源；不能升级为“已知天地灵气来源”。
- 陈缺第一次改变截气时机：不等叶中整缕最清楚，而在根部吸收刚出现变化时，只截取极小的一点。
- 当日共进行三次微量截取，分散在不同药苗、不同浇水时段；每次一痛即停。
- 结果：真木属灵气从近乎枯竭恢复为一小股，可清楚推动但仍远弱于CH004首次完整截取。
- 被截药苗当日没有出现CH004那种迅速卷黄；长期损耗是否存在仍UNKNOWN。

### 身体 / 炼身前置
- 三次截气后身体成本继续：右臂针痛、后腰寒意、明显饥饿。
- 夜间仍严格只运行《盗气残篇》三转，没有尝试第四转，也没有新增口诀。
- 三转经过右臂旧伤时，真气明显减少，但肩后酸热在真气衰减后没有同步立刻消失。
- 右臂功能出现第一次明确可见改善：由白天抬过胸口即明显牵痛，推进到夜间可第一次抬至与肩大致平齐并维持约两息后才明显收紧。
- 右臂仍受伤、仍疼，不能认定痊愈或正式炼身突破。
- SUSPECTS：部分“消失”的真气可能并非单纯散回外界，而是在经过受伤肉身时留下了某种身体变化；机制UNKNOWN。
