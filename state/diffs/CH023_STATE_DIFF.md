# CH023 STATE DIFF · 《废根也得湿着送》

## Canon Horizon
CH022 → CH023

## 时间 / 位置
- 三日南坡观察结算后的回药圃第一天，主要位于东畦/东棚。

## 陈缺
- 外棚药工与南坡验工双身份同时有效；回药圃后继续参与青须草起收、修根与分篓。
- 再次接触此前后棚→东畦的关键青须草：木气比后棚峰值明显收敛，根部苦味/药性更重，随后被正式起收。
- 白篓装可入药主根/合格侧根；青篓装过细、折断、发黑等“边损”。
- 亲证：刚从活株剪下的断须仍残留可感知木气，并会随离根时间快速衰散；晒干后几乎感不到。
- 陈缺仅从一根确定进入青篓的断须上极微截取一次；可成功引入一点木气，但比活苗来源更散、更短，右臂近肘弯出现细密针痛。
- 没有继续第二次截取、没有三转、没有次晨实验；断根来源是否适合长期使用仍UNKNOWN。

## 边损去向
- 陈缺原以为青篓边损会倒掉，实际西山药渣棚有专人来收。
- 西山杂役嫌青篓边根放得太干，要求下次放阴处，并用湿麻布盖住后运走。
- 明确去向：药圃青篓边损 → 西山药渣棚。
- WHY UNKNOWN：为何边损要湿着送、在西山做什么、与赵石异常关系均未确认。

## Knowledge Diff
### 陈缺
- KNOWS：新断边根存在一个短暂的残余木气窗口；极微量可以按残篇引入，但气更散、更易衰减。
- KNOWS：白篓正药与青篓边损有不同下游；青篓边损并非无人管理的废物，而被西山药渣棚收走并要求保持湿润。
- SUSPECTS：这一湿料去向可能与赵石对湿药渣的异常有关；尚无直接机制证据。

## Plot Diff
- 真炼身资源线：ADVANCED；发现比直接碰活苗更接近生产边角的潜在木气来源，但未建立稳定方案。
- 药材价值/生产链线：ADVANCED；同株从活苗→东畦→起收→正药/边损分流得到进一步纵向证据。
- 赵石湿渣线：REACTIVATED / ADVANCED；青篓边损实际流向西山药渣棚，为旧异常建立新的物料通道。

## Next Causal Hook
- 不能把青篓当“免费废料”直接使用；最自然下一步是确认西山为什么要求它保持湿润，以及这种处理是否与赵石真正的触发物有关。
