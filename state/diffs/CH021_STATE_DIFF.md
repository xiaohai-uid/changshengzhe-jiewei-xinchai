# CH021 STATE DIFF · 《看他能撑多久》

## Canon Horizon
CH020 → CH021

## 时间 / 位置
- 承接CH020次日清晨，推进至南坡曝晒场第一日收工后。
- 陈缺从药圃外棚被药房以三日借工令调往南坡曝晒场。

## 陈缺
- 身份仍为正式药圃外棚药工；外棚木牌与正常饭食保留。
- 右臂旧伤仍不能稳定吃重；南坡安排允许重物搭手，但普通工作照常。
- 三日观察期间：不碰活苗、不进后棚；药粥若遇运药日也暂停。
- 南坡第一日无新截气、无残篇运转、腹中无可用真气，但腰腿/整体耐劳未退回早期水平。
- KNOWS：既有身体变化至少有一部分不会随腹中真气散尽而立刻消失；仍不知道炼身完整机制与破境标准。

## 顾长槐 / 药房监督
- 灰衣药房弟子明确建立信息渠道：顾长槐已经看过CH020七日底账，并批准三日借工观察。
- 观察重点由右臂抬举改为全身耐劳：何时坐下、何时吃饭、收工是否能自行走回。
- 药房明确说明观察目的：看陈缺离开药圃、暂停活苗/药粥后，现有体力是否掉回去。

## 孙婆
- 新增角色：南坡曝晒场实际管事，姓名仅锁定称呼“孙婆”，其他背景/境界UNKNOWN。
- 生产逻辑：药材干湿与损耗优先，不为药房观察故意安排无意义重活；右臂重物可搭手，普通活不减。
- 与陈缺不存在保护关系；会因翻晒错误直接要求返工。

## Knowledge Diff
### 陈缺
- KNOWS：顾长槐已经通过七日底账看到自己的公开异常曲线。
- KNOWS：药房当前在做资源隔离后的持续耐劳观察。
- KNOWS：南坡已切断/半干药材的活木气远弱于药圃活苗。
- SUSPECTS：身体增长具有某种累计性；完整形成机制仍UNKNOWN。

## Relationship Diff
- 陈缺 ↔ 顾长槐/药房：从被动连续记录升级为有明确变量控制的三日借工观察；监督更深，但正式药工身份没有被清零。
- 陈缺 ↔ 孙婆：建立纯生产关系；孙婆按晒药质量使用陈缺，不负责解释药房目的。

## Plot Diff
- 七日连续观察线：ADVANCED → 三日资源隔离观察已启动。
- 真炼身/身体承载线：ADVANCED；首次在无新真气、无活苗条件下确认耐劳资产不会立刻归零。
- 药圃职业价值线：ACTIVE；外棚身份与饭食在观察期间保留。

## Next Causal Hook
- 三日观察必须结算；重点不是再次证明“能熬”，而是白骨山如何重新定价一个异常但稳定产出的药工。
