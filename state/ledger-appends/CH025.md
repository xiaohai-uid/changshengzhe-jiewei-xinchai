# CH025《别让这筐死透了》 · Chapter Ledger Append

- 西山收青篓延误，药圃边根累积；陈缺首次从多株刚剪下、确定属于边损的细根中分散极微取气。
- 陈缺没有运转完整三转，只用《盗气残篇》前段把多缕散气往腹中轻引；半个时辰后勉强聚成极薄一层真气。
- 多来源断根之气比活木来源更散、更难收束；陈缺分神时右臂内侧出现针麻，并差点把应进白篓的完整侧根分错。
- 陈缺立刻停止继续补气，优先保证药工判断；因此边损分散取气被证明可行，但效率低、注意力成本高，并有经络/工作错误风险。
- 许管事明确收到西山要求：隔夜青料只盖湿布，不能擅自加渠水。
- 因西山湿车坏轴，赵石临时推空筐到药圃；他只负责空筐/干路，仍主动避开湿货。
- 赵石右手碰到未新浇黑壶液、但覆盖隔夜边根的湿麻布后，出现较轻的手指僵紧反应；程度弱于此前湿渣车。
- 赵石说明其西山工作经验：干渣称重、装筐、外运；湿料是另一类活，有药房的人来收。他不知道完整机制。
- 赵石说“他们不怕湿料烂，怕它死透”；该句记录为赵石基于工作观察形成的认知，不等同作者层终极事实。
- 药圃实际把未完全坏死的边损放青篓送西山；已经腐烂/死透的烂根烂叶放黑盆倒坑，西山不要。陈缺触碰黑盆腐根时感不到木气。
- 西山瘦汉傍晚再次要求药圃“别让这筐东西死透了”。
- CH025结束时，陈缺已找到不必直接伤活苗的潜在边损取气路径，但该物料有明确西山用途，方法本身又存在气散、分神和经络负担，因此尚非安全稳定资源。
- 陈缺仍未正式突破炼身，无新战斗术法。
