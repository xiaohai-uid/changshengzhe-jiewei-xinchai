# CH019《干得快，就再多干一畦》 · Chapter Ledger Append

- 陈缺从西山药渣棚返回药圃后，许管事安排其参与后棚缓苗翻看、松泥、修烂根、扶叶和遮帘管理。
- CH017那株外观挺拔、木气旺盛但“现在不值东畦”的青须草幼苗已栽在后棚最外侧浅槽，仍健康存活、木气更旺，苦涩药味仍淡。
- 后棚退苗仍按批次木签管理，并非无主废料；完全死透才拔，其余继续缓养并可能未来再筛。
- 当日午饭为粗面饼与稀粥，无药粥；正式药工食额能压下一部分高劳动后的饥饿，但不能完全消除。
- 后棚半蹲劳动自然造成陈缺后腰、大腿与膝弯明显劳损；右臂反而只承担轻扶苗等低负荷动作。
- 陈缺因右臂处于七日连续记录中，刻意不让所有增长继续集中表现于右臂；当日面对旺木气幼苗仍没有截气，当夜也没有运转《盗气残篇》。
- 次日清晨腰腿仍按普通劳损方式疼痛，仅较夜里自然松缓一点；这成为“单纯睡一夜”对照。
- 第二日后棚工作量继续增加，腰腿再次形成真实劳损。
- 傍晚放水时，陈缺从后棚旺木气青须草上只截取极少一缕木气，比此前东畦微截更少；立即停手，没有第二次截取，青苗当时没有即时可见变化。
- 当夜陈缺先补充晚饭留下的半块饼与水，再严格按《盗气残篇》既有路线三转而止。
- 真气经过白日劳损最明显的后腰与两侧大腿时明显变薄，后腰/腿根留下酸热；三转后小腹真气逐渐难以感知，但腰腿酸热仍持续。
- 次日清晨大腿根与后腰恢复明显快于前一次普通休息对照：仍酸、仍累，但站起和伸直时的滞涩显著减少。
- 真气三转后的持久变化由旧伤右臂扩展到普通劳动造成的腰腿劳损；这强化“真气可能在受负荷部位被消耗并留下较持久肉身变化”的工作假设，但不等于完整炼身法或正式破境。
- 陈缺右臂公开表现仍维持过肩约半寸、仍疼；许管事认为恢复速度慢下来后“这样才像养伤”。
- 因腰腿恢复与耐力提升，陈缺次日上午明显更快完成两排后棚浅槽工作。
- 许管事没有追问效率提升原因，而是直接把后棚更里面又一整片浅槽/一畦交给陈缺继续处理。
- 老药工对陈缺说“现在知道为什么我们干活从来不快了？”，点明药工效率提高会直接换来更多工作量。
- 本章未正式突破炼身境，没有新增战斗能力，也没有确认木气、药性与肉身成长的完整机制。
