# CH024《雨水没这个味》 · Chapter Ledger Append

- 三日后午后，陈缺第一次按南坡“验”牌执行周期性半日验工。
- 西山青篓湿料短暂停在南坡阴棚；料中可见细须、断根、伤叶、发黑侧根，与药圃青篓边损类型一致。
- 西山瘦汉从车底取出黑陶壶，以壶中液体重新浇湿青篓麻布；液体带明显苦腥味，与普通雨水/渠水不同。
- 被重新浸湿的断根仍有可感知微弱木气，明显强于自然放干后的边根。
- 孙婆说西山长期收药圃割下、药房煮剩、前库退回等“能湿的”边料；白签成药进前库，青料去西山，各有自己的记录流程。
- 陈缺手背沾到少量湿料液后只有轻微发涩/紧绷，没有出现赵石式右手失控，也没有虫性反应。
- 陈缺由此不再把赵石异常简单归因于“湿”；他怀疑西山特殊湿料或苦腥处理液是更具体触发因素，但未确认成分/机制。
- 陈缺在本次南坡验工中独立验出一篓底层返软根；孙婆据此让整篓返工，并调整签数，证明其验工职责有真实生产责任。
- 次日上午回药圃，陈缺没有再从断根取气，只把青篓往阴处拖以符合已观察到的西山收料要求。
- 西山瘦汉面对陈缺关于“泡”的试探，只说“西山的活，少问”；黑壶成分、湿料最终用途仍UNKNOWN。
- CH024结尾，陈缺明确知道苦腥味来自西山额外处理，不是雨水本身。
