# CH020《这点力气，已经记进去了》 · Chapter Ledger Append

- CH020承接CH019章末同一工作日上午，陈缺刻意压低后棚第三畦的工作速度，但午时前仍完成约两畦半，真实劳动效率高于前一日。
- 陈缺右臂公开抬举状态仍维持过肩约半寸；腰腿与整体耐劳能力却继续提升，表现为更能久蹲、持续翻苗和较少出现明显僵滞。
- 许管事按实际工量记录陈缺，当日按约两畦半结算，并明确次日按三畦派工；陈缺的身体增长被药圃直接转化为新增劳动义务。
- 后棚此前木气旺盛但被判“不值东畦”的青须草，经约三日缓养后木气较峰值略弱，根部苦味/药性表现却明显变重。
- 许管事判断该青须草“前几日是草，熬过这三天，它便是药”，并把它与另外两株苗迁入东畦。
- 另有一株枝叶旺、木气较盛的苗因根味不足被许管事评价为“白长肉”，未迁入东畦。
- 陈缺确认一个新的可见事实：自己感知的木气强度不能直接等同于白骨山当前判断的药性/药材价值；完整机制仍UNKNOWN。
- 陈缺在移栽已升入东畦的药苗时主动不截气，避免在新增高价值、可追责药材上制造损耗。
- 当日晚间，一名陈缺未见过的灰衣药房弟子到外棚收取“七日底账”；其姓名、境界、具体职司均UNKNOWN。
- 该弟子查看陈缺记录时注意到“右臂公开恢复停滞、腰腿耐劳与工量持续提高”的组合，并与许管事核对。
- 许管事只按生产事实回答：陈缺手上不敢吃重，但更能走、蹲、持续干活；未替其解释异常来源。
- 其他人员记录被收入竹筒，陈缺的记录被灰衣药房弟子单独扣在掌中带走。
- CH020结束时，陈缺知道自己的七日记录已被药房单独筛出，但不知道原因、接收者与下一步处置。
- 本章没有正式炼身突破，没有新战斗术法，也没有揭示木气转化、药性形成或“天地亦食修士”的完整机制。
