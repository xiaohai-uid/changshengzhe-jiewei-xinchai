# CH015《虫没长，伤倒先好了》 · Chapter Ledger Append

- 药圃外棚试用第三日清晨，陈缺按原定安排被带到药房东侧偏院进行三日复验。
- 许管事把候工木片交给带人灰衣；木片已记录陈缺药苗无明显异常损耗、右手恢复较快等事实。
- 陈缺在药房东侧偏院看到赵石；赵石比南二时期进一步枯瘦，右腕暗红旧痕仍在，右手仍会抽搐。
- 两只封闭黑陶罐经过并伴随更浓苦腥味时，赵石右腕暗痕明显加深，藏在袖中的右手发生强烈不受控抽搐。
- 赵石主动要求离开药房里间，愿去药渣外棚、曝晒场、搬空篓等外侧工作，只要求不继续接触里间那几桶东西。
- 赵石一直保留CH011南二半日借工木签，并把该工作记录作为自己在外侧环境能够劳动的证明。
- 赵石当场自述“南二那半日，我一个人抬过几十只重药篓，搭手的人和老周都签字画了押”；该精确数量只锁定为赵石自述，不锁成客观确认数量。
- 顾长槐准赵石去西侧药渣棚三日试用；药渣棚仍归药房名下，若右手再次抽搐到拿不住铁铲，则送回药房里间。
- 陈缺与赵石短暂碰面，只确认彼此当前流转，没有交换药房具体经历或无虫真修秘密。
- 陈缺三日复验中，银针两次均只有极轻微反应，延续此前“体内动静极弱但非完全无反应”的异常表现。
- 陈缺右臂复验时可举过肩约半寸，肩后仍有真实紧绷阻滞，重物仍拿不稳；顾长槐触诊确认筋肉较前几日更松泛。
- 顾长槐根据药圃三日仅一株损耗、南二连续留用及陈缺当前可工作状态，决定不把他扣回药房里间，而是正式转为药圃外棚药工。
- 陈缺获得写有“外棚”并盖药房暗红印的小木牌。
- 正式外棚药工按药工食额领饭；较候工多一块杂粮面饼，运药日可能有带药渣的温补稠粥。
- 白绳不摘、黑点保留；未来七日由药圃连续记录腕检与伤势脉案并送药房，陈缺暂时不用再专程跑药房复验。
- 陈缺返回药圃后开始按正式药工工作量干活；右肩旧伤仍疼。
- CH015午时陈缺实际领到并吃完一块粗面饼与一碗温热药粥；职业价值第一次稳定兑换成可持续口粮资源。
- 陈缺无虫真引气、活木截气和真气→肉身工作假设仍未被顾长槐/药房确认。
